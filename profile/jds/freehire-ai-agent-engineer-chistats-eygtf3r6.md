**About the Role:**

We are looking for an engineer to build AI applications and agents on top of frontier AI platforms. In this role, you won't just be writing prompts; you will be designing how these agents think, plan, and use real tools and APIs to get actual work done for users.

**What You Will Do:**

\- Build agentic workflows: Design and develop multi-step agent workflows using LangGraph or a similar framework - covering planning, picking the right tools, breaking down tasks, handling memory, and adding human-in-the-loop checkpoints.

\- Design and build agent tools: Figure out what tools the agent actually needs to do its job, and build them - including setting up MCP servers to safely connect agents to SQL databases and other data sources.

\- Connect apps and services: Integrate third-party apps and services using SDKs, function calling, and REST or GraphQL APIs.

\- Handle data and memory: Set up context and memory management, including RAG, session state, and user personalization.

\- Tune and optimize: Keep refining prompts, system instructions, and tool schemas so the agents run reliably, stay fast, and don't burn through tokens unnecessarily.

\- Test and track performance: Set up evaluations and monitoring to see how agents behave in the wild - tracking success rates, figuring out why things fail, and keeping an eye on latency and token costs.

\- Keep things secure: Manage authentication and permissions for connected apps (OAuth 2.0, API keys, scoped access) while keeping user data safe and private.

\- Work with the team: Partner with product and design folks to turn user ideas into working agent features, build quick prototypes, and bring in useful updates from new AI lab releases.

**What We Are Looking For:**

**Agentic AI & Multi-Agent Systems:**

\- Workflow design and tuning: You know how to design multi-agent systems and state graphs (like in LangGraph or LangChain), and you know how to tune their behavior, cut down latency, and optimize token costs.

\- Tool design & MCP: You can decide which tools an agent needs, write clean tool schemas, and build MCP servers to hook agents up to SQL databases and external APIs.

\- Context engineering: You know how to manage the context window smartly so the agent always has the right information without getting confused or bloated.

\- LLM APIs & Frameworks: You have hands-on experience with frontier model APIs (Anthropic, OpenAI, Google) - specifically tool calling, structured outputs, and streaming - and have built with frameworks like LangGraph, LangChain, Claude Agent SDK, OpenAI Agents SDK, LlamaIndex, CrewAI, or AutoGen.

**Data Ingestion, RAG & Evaluation:**

\- Document ingestion: You can build solid ingestion pipelines using tools like Docling and Unstructured.

\- Storage and chunking decisions: You know how to decide the right chunking strategy, pull out the right metadata, choose how to store embeddings, and set up clean storage policies on vector databases (like Pinecone, Weaviate, pgvector, Chroma, or Qdrant).

\- Retrieval and evaluation: You can design retrieval pipelines and actually measure whether your chunking and retrieval are working well using frameworks like Ragas or DeepEval.

**Software Engineering:**

\- Strong Python & Async skills: You are very comfortable with Python, especially async programming (asyncio), background jobs, and event-driven setups for tasks that take a while to run.

\- Backend & Cloud: You can build clean APIs (FastAPI, Flask, or similar), handle OAuth 2.0 and API permissions, and deploy using Git, CI/CD, Docker, and cloud platforms (AWS, GCP, or Azure).

**How You Work:**

\- Comfortable with moving fast: The AI space changes every week - you are comfortable with ambiguity, rapid prototyping, and clearly explaining your design trade-offs to the team.
