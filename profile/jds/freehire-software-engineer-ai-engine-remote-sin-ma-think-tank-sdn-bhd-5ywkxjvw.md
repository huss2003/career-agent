【職務目標】

負責 TGSA「企業通（Enterprise OS）」平台中單一 AI 引擎服務（Engine Service）的系統開發與維護。主要工作內容包含 PostgreSQL 資料庫設計、Python FastAPI 後端 API 開發與前端 Nuxt (Vue) 系統整合。

本職位需依據產品邏輯與需求文件（PRD），將邏輯轉換為可運行的系統功能，確保引擎模組具備良好的資料結構設計、API 穩定性與前後端整合能力。本職位主要聚焦於單一引擎服務開發，不需負擔整體平台架構設計，非常適合希望深耕 AI 應用落地與後端架構的工程師。

【核心職責】

1. 引擎開發：依據 PRD 負責開發與維護企業通中的單一 AI 引擎服務。
2. 資料庫設計：負責 PostgreSQL (Supabase) 資料庫建構、ERD 設計、SQL 優化，並配合多租戶系統（Tenant\_ID）確保資料隔離。
3. 後端 API 開發：使用 Python FastAPI 建立 RESTful API，實作 AI 生成與業務邏輯，提供穩定服務。
4. API 規範與文件：設計符合 OpenAPI / Swagger 標準的 API，落實「文件優先（Doc-First）」原則，撰寫 SDD 確保系統可維護性。
5. 前後端整合與通訊：與前端協作整合 Nuxt (Vue) 系統，並實作 WebSocket 即時通訊機制。
6. 架構與資安遵循：依照軟體架構師制定之規範開發，實作 JWT / OAuth2 驗證與敏感資料安全處理。
7. 團隊協作：參與每週例會，向 PM 回報進度，並與測試工程師合作修正問題。

【技術要求與資格】

- 核心技術：熟悉 Web 系統開發，具備 PostgreSQL (Supabase) 與 Python (FastAPI) 實務經驗。
- 資料庫經驗：熟悉 PostgreSQL 架構、ERD 設計、索引與 SQL 查詢優化。
- API 開發：具備 RESTful API 設計經驗，能熟練運用 FastAPI 產出完整 OpenAPI / Swagger 文件。
- 前端整合能力：主要搭配框架為 Nuxt (Vue)；具備 React / Next / Vue 等前端框架開發與串接經驗者均可提出討論。
- 基礎架構與操作：熟悉 Linux Command Line 基礎操作、Git / Gitflow 工作流程。
- 系統整合：具備 Redis 快取或 Docker 容器化部署之實務經驗。

【加分項目】
