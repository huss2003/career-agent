Job Description

**About the role**

We’re moving towards a model where engineers own features end-to-end.

With AI speeding up implementation, coding is no longer the bottleneck. The focus has shifted to understanding problems, shaping solutions, managing dependencies, and delivering high-quality outcomes.

We’re looking for senior engineers who are comfortable taking a feature from idea → plan → build → test → release, while working closely with stakeholders and product teams.

**What you’ll be doing**

- Own features end-to-end (planning → implementation → testing → handover)

<!--THE END-->

- Work directly with product, design, stakeholders, and other teams to understand requirements

<!--THE END-->

- Break work into vertical slices that deliver real user value

<!--THE END-->

- Create clear implementation plans (approach, edge cases, risks, dependencies)

<!--THE END-->

- Build across .NET (backend) and React (frontend)

<!--THE END-->

- Use AI tools (Claude, Copilot, etc.) to accelerate development

<!--THE END-->

- Write and maintain automated tests (Playwright for E2E)

<!--THE END-->

- Demo early, gather feedback, and iterate quickly

<!--THE END-->

- Identify and manage dependencies proactively to avoid rework
