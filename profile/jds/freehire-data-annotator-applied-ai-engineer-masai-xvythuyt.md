**About the Role**  
We are looking for experienced Applied AI Engineers, AI Engineers, and Generative AI Engineers to contribute to specialised data annotation, technical evaluation, and AI model training projects.

This is not a conventional data annotation role. The work involves advanced technical evaluation of LLM-based applications, AI agent workflows, retrieval-augmented generation (RAG) systems, prompt engineering, and AI-generated code and outputs.

Selected professionals will work on tasks that require a strong understanding of modern AI architectures, generative AI frameworks, LLM integrations, agentic workflows, and practical implementation of AI-powered applications.

The objective is to improve the accuracy, reasoning, performance, and reliability of AI systems by generating, reviewing, annotating, and evaluating technically complex datasets and AI-generated outputs.  
**Key Responsibilities**

- **AI Application Analysis:** Review and understand existing AI-powered applications, analyse implementation logic, evaluate system architecture, and assess technical correctness.
- **LLM Architecture Evaluation:** Analyse large language models, transformer-based architectures, model configurations, and LLM integration workflows.
- **RAG Pipeline Evaluation:** Assess retrieval-augmented generation systems, embedding models, vector databases, retrieval mechanisms, and context-generation workflows.
- **AI Agent Evaluation:** Evaluate AI agent architectures, tool-calling mechanisms, multi-agent workflows, orchestration logic, and autonomous task execution.
- **Technical Data Annotation:** Perform high-quality annotations on AI-related datasets, including prompts, responses, code, agent workflows, and technical documentation.
- **AI-Generated Output Evaluation:** Assess AI-generated outputs for factual accuracy, logical reasoning, contextual relevance, instruction adherence, and technical correctness.
- **Prompt Engineering & Evaluation:** Review and evaluate prompts, system instructions, prompt chains, and AI-generated responses for quality and effectiveness.
- **Code-Level Assessment:** Review Python-based AI implementations, identify logical errors, evaluate integration approaches, and suggest technically sound corrections.
- **AI Model Integration & Fine-Tuning:** Evaluate LLM APIs, model integrations, fine-tuning approaches, inference pipelines, and model deployment workflows.
- **AI Framework Evaluation:** Assess implementations built using frameworks such as LangChain, LlamaIndex, and other AI application development frameworks.
- **Documentation & Reasoning:** Provide clear technical explanations, annotations, justifications, and structured feedback for evaluation tasks.
- **Quality Assurance:** Maintain high annotation accuracy and consistency while following project-specific guidelines and evaluation standards.
