**Roles & Responsibilities:**

  - Design, develop, optimize, and maintain asynchronous backend services using Python and FastAPI.
  - Build high-performance APIs capable of handling high-volume requests with minimal latency.
  - Implement non-blocking operations using asyncio and Uvicorn.
  - Manage database connection pools and optimize backend performance.
- **LLM Evaluation & Regression Testing**
  
  - Develop deterministic LLM evaluation and regression testing pipelines.
  - Validate model consistency, output quality, and structured response schemas using Pydantic.
  - Monitor agent stability and identify inconsistencies in AI-generated responses.
- **Multimodal Data Processing**
  
  - Develop data ingestion pipelines for processing text, images, and videos.

  - Build data extraction, validation, filtering, and cleansing pipelines.

- **Testing & Code Quality**
  
  - Develop comprehensive unit and integration test suites.
  - Follow test-driven development practices.
  - Write clean, modular, documented, and maintainable code.
  - Focus on simplicity, readability, performance, and reliability.
