**Role & responsibilities**

We are looking for a **hands-on Full Stack Engineer with 5+ years of experience** who can build modern enterprise applications and use GenAI to accelerate and enhance software development.

The ideal candidate will have strong experience with **React, TypeScript and Vite**, along with a backend technology such as **.NET/C#, Node.js or Python**. We are looking for someone who can understand a business problem, design the solution, build it and take it through to production.

The candidate should also have practical exposure to **GenAI and AI-assisted development**, with an interest in building AI-enabled enterprise applications.

**Preferred candidate profile**

- Build modern web applications using **React, TypeScript and Vite**.
- Develop backend services and REST APIs using **.NET/C#, Node.js or Python**.
- Work with business stakeholders to understand requirements and translate them into working solutions.
- Own development from **requirements and design through coding, testing and deployment**.
- Integrate applications with enterprise APIs, databases and external systems.
- Build or integrate **GenAI capabilities** into enterprise applications.
- Apply AI-assisted development tools across coding, testing, debugging, documentation and code review.
- Build solutions using **Power Platform**, including Power Apps, Power Automate and Dataverse, where appropriate.
- Follow engineering best practices for security, testing, code quality, Git and CI/CD.
- Explore emerging AI engineering approaches such as **RAG, AI Agents and MCP** and apply them where relevant.

Must-Have Skills

- **5+ years of software development experience**.
- Strong hands-on experience with **React and TypeScript**.
- Experience building React applications using **Vite**.
- Strong experience with at least one backend technology:
  
  - C# / .NET
  - Node.js
  - Python
- Experience building and consuming **REST APIs**.
- Experience with **SQL and/or NoSQL databases**.
- Good understanding of application design, integration, security, testing and CI/CD.
- Practical experience using **GenAI/AI coding tools** in software development.
- Ability to independently take features or applications from **requirement to production**.
- Good communication and problem-solving skills.

Good to Have

Candidates do **not need to have all** of the following:

- Power Apps, Power Automate and Dataverse
- Building GenAI-enabled applications
- RAG and vector/semantic search
- AI Agents / Agentic AI
- MCP (Model Context Protocol)
- Prompt and context engineering
- GitHub Copilot, Codex or similar AI engineering tools
- Spec-Driven Development approaches
- AI guardrails and evaluation techniques

What We Are Looking For

We want a **strong software engineer first**, with a modern AI mindset.

The ideal profile is:

**React + TypeScript + Vite + Backend + APIs + Enterprise Development**

with practical exposure to:

**GenAI / AI-assisted Engineering**

and preferably some experience with:

**Power Platform / RAG / AI Agents / MCP**

The candidate does **not** need to be an AI architect or an expert in every emerging AI technology. We are looking for someone who is **hands-on, adaptable, curious and capable of learning and applying new AI engineering approaches quickly**
