**Designation: QA Automation Engineer**

**Preferred Experience: 3+ Years**

**Job Summary :**

We are hiring SDETs to build our firm-wide QA automation practice, starting with automated regression suites for our product's core platform and for each of its client deployments.

You will join a small QA Center of Excellence that sets one automation standard for the whole firm: Playwright with Python and pytest, run in CI, with AI-assisted test creation and maintenance.

**Key responsibilities**

- Design and build the automation framework (Playwright + Python + pytest) and its reusable components, following the CoE's coding and naming standards.
- Convert standardized manual test cases into automated suites: one Core regression suite, plus a delta suite for each client deployment.
- Automate tests across all layers: web UI journeys, REST APIs, integrations with mocked client systems, and data/AI pipeline outputs checked against golden datasets.
- Automate IQ checks (installed versions, configuration, connectivity) and OQ functional tests, and support PQ end-to-end business scenarios.
- Make every test traceable to a requirement and test case ID, and make sure each run produces audit-ready evidence: step logs, screenshots, timestamps and environment details.
- Integrate suites into CI pipelines: on every pull request, nightly per client fork, and on demand for release sign-off.
- Use AI tools (Claude Code, Playwright MCP) to generate, explore and repair tests, and review all AI-generated code before it is merged.
- Keep suites reliable: fix flaky tests, manage test data and environments, and report coverage and quality metrics.
- Investigate failures, log clear defects, and work with developers and functional QA to resolve them.
- Write how-to guides and coach other projects as they adopt the framework.

**Must-have skills and experience**

- 3+ years in software testing, including at least 3 years building test automation in code (not record-and-playback only).
- Strong Python, including pytest: fixtures, parametrization, markers, plugins.
- Hands-on Playwright with Python for UI and API automation: locators, auto-waiting, fixtures, tracing, and the page object model.
- API test automation for REST services using Playwright's built-in API testing: authentication, schema checks, negative tests.
- SQL, plus validating data in databases or files.
- Git workflows and running tests in a CI/CD pipeline (GitHub Actions, GitLab CI, Jenkins or Azure DevOps).
- Experience turning manual test cases into maintainable automated suites, with test case IDs carried through to reports.
- Clear written English for defect reports, test evidence, and documentation.

**Good-to-have skills :**

- Testing in GxP-regulated environments: IQ/OQ/PQ protocols, Computer System Validation (CSV) or Computer Software Assurance (CSA), GAMP 5, and 21 CFR Part 11 / EU Annex 11 data-integrity expectations.
- Testing data pipelines or ML/AI outputs in Python: dataset-level checks and accuracy thresholds with pytest and pandas.
- AI-assisted test development with Claude Code and the Playwright MCP server, including reviewing and correcting AI-generated tests.
- Building audit-ready test evidence reports (e.g. Allure) with step logs, screenshots and Playwright traces.
- Docker, test-environment set-up, and basic cloud knowledge (AWS or Azure).
- ISTQB or equivalent certification.
