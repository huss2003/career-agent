**Join Amity Accentix (formerly TrueVoice), a Subsidiary of Amity AI Holdings**

Amity Accentix is looking for a Software Engineer to help build and scale our AI Voicebot Platform, powering intelligent voice conversations for enterprise customers in both Thai and English.

You'll work across the full voice technology stack, from telephony and real-time audio streaming to speech recognition (ASR), large language models (LLMs), and text-to-speech (TTS). You'll also contribute to the web applications that allow customers to build, manage, and monitor their voicebots.

This is a hands-on engineering role where you'll build production-ready systems, integrate cutting-edge AI technologies, and deliver solutions used by real enterprise customers.

**Explore more about us at:** Amity Website

## What You'll Do

- **Develop Backend Services:** Build and maintain Node.js services that power real-time voice conversations, including audio streaming and WebSocket integrations.
- **Integrate AI Technologies:** Connect and optimize ASR, TTS, and LLM services from multiple providers, focusing on response latency and Thai language accuracy.
- **Build Frontend Features:** Develop and enhance customer-facing applications using Vue.js 3, including the Voicebot Flow Builder and monitoring dashboard.
- **Deliver Customer Solutions:** Customize, deploy, and maintain voicebot solutions for enterprise customers across cloud and on-premise environments.
- **Ensure Quality & Security:** Write automated tests, review code, and follow secure development practices.
- **Maintain Production Systems:** Implement monitoring, logging, and tracing, troubleshoot production issues, and participate in incident response.
- **Develop Internal Tools:** Build internal applications and automation using our existing technology stack and LLM APIs.

## What We're Looking For

- 3+ years of experience developing production backend applications using Node.js with JavaScript or TypeScript.
- Strong understanding of JavaScript fundamentals, including async/await, streams, Buffers, and the event loop.
- Experience building REST APIs and WebSocket services using Express.js.
- Experience with MongoDB, including data modelling and query optimization.
- Working knowledge of Vue.js 3 and the ability to develop frontend features independently.
- Familiarity with Docker, Docker Compose, Linux servers, and CI/CD pipelines.
- Hands-on experience with at least one major public cloud platform, including cloud infrastructure, networking, and access management.
- Experience with application monitoring, logging, and distributed tracing.
- Good understanding of software testing, code reviews, and secure coding practices.
- Good written and spoken communication skills in both Thai and English.
- Bachelor's degree in Computer Science, Computer Engineering, or a related field, or equivalent practical experience.
