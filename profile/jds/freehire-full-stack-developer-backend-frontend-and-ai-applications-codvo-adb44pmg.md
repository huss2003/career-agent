Full Stack Developer Backend, Frontend & AI Applications

**Role Overview**

We are looking for a Full Stack Developer with hands-on experience in backend development, frontend technologies, API development, databases, and AI-powered applications. Experience with Microsoft Power Platform and SharePoint is an added advantage.

**Key Responsibilities**

- Develop backend services using Node.js, Python, Java, or C#.
- Build responsive frontend applications using React, Angular, or Vue.
- Design and maintain REST APIs, business logic, authentication, and authorization.
- Design databases, optimize queries, and manage transactions.
- Integrate enterprise systems, third-party APIs, and frontend applications.
- Build AI-powered features using LLM APIs, RAG, and agent workflows.
- Implement automated testing, logging, monitoring, and performance optimization.
- Support application deployment and production troubleshooting.

**Required Skills**

- Strong hands-on experience in at least one backend technology: Node.js, Python, Java, or C#.
- Frontend development using React, Angular, or Vue with JavaScript and TypeScript.
- REST API development, integration, and secure authentication.
- SQL databases, database design, and query optimization.
- OAuth 2.0, OpenID Connect, JWT, and role-based access control.
- Unit testing, integration testing, Git, and CI/CD.
- Experience integrating OpenAI, Azure OpenAI, or other LLM APIs.
- Understanding of prompt engineering, RAG, embeddings, vector search, and AI workflow orchestration.

**Preferred Skills**

- Azure/AWS, Docker, Redis, RabbitMQ, Kafka, and MongoDB.
- LangChain, LangGraph, or Semantic Kernel.
- Power Apps, Power Automate, Dataverse, SharePoint Online, Microsoft Graph API, and Copilot Studio.
- Microservices, event-driven architecture, and production monitoring.
