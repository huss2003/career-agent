About the Role:

**Role Overview**

We are looking for a Full-Stack MERN & AI Developer to architect, build, and scale intelligent web applications and conversational AI chat agents. You will own end-to-end feature delivery across our React frontend, Node.js/Express microservices, and MongoDB data layer while integrating LLM pipelines, vector databases, and real-time streaming chat interfaces.

**Key Responsibilities**

**Full-Stack Application Development:** Design, build, and maintain responsive web applications using MongoDB, Express.js, React, and Node.js.

**AI & Chat Agent Engineering:** Architect and deploy conversational AI chat agents using LLM APIs (OpenAI, Anthropic, Gemini) and orchestration frameworks (LangChain, LangGraph, or Vercel AI SDK).

**Real-Time Streaming & State Management:** Implement low-latency, token-streaming chat interfaces using WebSockets, Server-Sent Events (SSE), and modern React state management.

**RAG & Context Pipelines:** Build Retrieval-Augmented Generation (RAG) workflows, manage embeddings, and optimize vector search (MongoDB Atlas Vector Search, Pinecone, or Qdrant) for accurate agent responses.

**API & Tool Calling Integration:** Develop secure RESTful APIs and webhook handlers that allow AI agents to execute tool calls, query internal databases, and interact with third-party platforms.

**Database & Performance Optimization:** Design scalable MongoDB schemas, build efficient aggregation pipelines, and optimize both frontend rendering and backend query latency.

**Testing, Security & Deployment:** Write automated unit and integration tests, enforce authentication/RBAC protocols, and manage CI/CD deployments on cloud infrastructure.

**Required Qualifications**

**Experience:** 3 to 6 years of hands-on software engineering experience building production web applications.

**MERN Core:** Deep proficiency in JavaScript (ES6+), TypeScript, React (hooks, performance optimization), Node.js, Express.js, and MongoDB.

**Conversational AI:** Proven experience building and shipping LLM-powered chat agents, prompt engineering, structured outputs, and function/tool calling.

**Real-Time Protocols:** Practical experience with WebSockets (Socket.io) or SSE for real-time messaging and streaming UI updates.

**System Fundamentals:** Solid understanding of RESTful APIs, JWT/OAuth authentication, Git workflows, and asynchronous programming.

**Preferred Qualifications**

Experience with Next.js (App Router, Server Actions) and Tailwind CSS.

**Familiarity with enterprise conversational AI platforms (such as Kore.ai, Dialogflow, or Rasa) and multi-agent routing.**

Experience with Redis for session caching, rate limiting, and background job queues.

Exposure to Docker, Kubernetes, and cloud platforms (AWS, GCP, or Azure).

Understanding of LLM evaluation, guardrails, token cost optimization, and observability tools (LangSmith, Helicone).
