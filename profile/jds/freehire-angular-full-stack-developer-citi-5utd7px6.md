**Job Summary:**

We are seeking a UI Developer with a strong emphasis on Angular-based frontend architecture and development to join our team. You will play a key role in designing, developing, and scaling responsive, modular, and high-performance applications used daily. A deep understanding of secure coding practices and financial-grade UI/UX is crucial.

**Key Responsibilities:**

- Participate in the development and optimization of web applications using **Angular (v16+) and modern JavaScript/TypeScript.**
- Collaborate with **UX/UI designers** to translate Figma prototypes into pixel-perfect, accessible web components.
- Ensure cross-browser compatibility and performance optimization for all frontend code.
- Implement **CI/CD pipelines, unit/integration testing, and code reviews to maintain high code quality.**
- Work closely with **DevOps and Cloud teams** to deploy, monitor, and maintain applications in Docker/Kubernetes environments.
- Participate in product planning and architectural decisions with Engineering and Product stakeholders.

**Required Skills & Qualifications:**

- 4+ years of professional software development experience.
- Strong expertise in **Angular (v16+), RxJS, TypeScript, HTML5, SCSS/CSS3.**
- Solid experience in **full stack development using Java (Spring Boot) or Python.**
- Experience integrating **RESTful APIs** and working with role-based access control.
- Experience with **PostgreSQL, MongoDB, or other relational and NoSQL databases.**
- Familiarity with **CI/CD tools** (GitHub Actions, Jenkins, GitLab CI) and containerization via Docker.
- Knowledge of microservices architecture, API gateways, and cloud platforms (**AWS/GCP/Azure**).

**Preferred Qualifications:**

- Experience with WebSockets, real-time data handling, and financial charting libraries (e.g., Highcharts, D3.js).
- Experience with Kubernetes, Docker is good to have.
- Proficiency in leveraging AI-driven coding platforms such as Devin, Claude, and other generative AI tools to support application development, code optimization, and automation would be good to have.

**Education:**

- Bachelor’s degree/University degree or equivalent experience
