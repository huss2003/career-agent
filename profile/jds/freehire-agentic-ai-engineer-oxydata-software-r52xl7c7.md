# **Agentic AI Engineer**

**Location:** Petaling Jaya, Selangor, Malaysia

**Work Mode:** Hybrid

**Employment type:** Permanent

**Experience Level:** 1–4 years

**Work Eligibility:** Applicants must have the legal right to work in Malaysia. Visa sponsorship is not available for this position.

Oxydata Software Sdn Bhd established since 2012, helping regional enterprises drive digital transformation through Agentic AI Services, AI Automation & Integration, Data Engineering, AI Training, and IT Managed Services. We are a lean, high-impact team where engineers work directly on cutting-edge AI products serving enterprise clients across Malaysia and the region.

We are seeking an experienced Agentic AI Engineer to design and implement advanced multi-agent AI systems for enterprise automation.

### **Responsibilities**

- Design and implement multi-agent pipelines using LangGraph and/or CrewAI, including agent role definition, task decomposition, inter-agent communication, and state management.
- Develop supervisor/worker agent architectures for complex, multi-step reasoning tasks.
- Integrate AI agents into business process automation pipelines and deploy production automation workflows.
- Implement tool-calling agents with access to APIs, databases, search, and file systems.
- Integrate GPT Vision or equivalent for document parsing, screenshot analysis, and visual data extraction.
- Develop multimodal pipelines combining text, image, and structured data inputs.
- Integrate Retrieval-Augmented Generation (RAG) pipelines and utilise vector search for agent knowledge grounding.
- Apply prompt engineering for agent personas, reasoning chains, and output formatting.
- Deploy agentic systems on self-hosted VPS infrastructure and expose agent capabilities via API endpoints (FastAPI).
- Implement observability, logging, and error handling for long-running agent workflows.

### **Requirements**

### **Must-have:**

- Bachelor’s degree in Computer Science, Software Engineering, Artificial Intelligence, or a related field.
- Applicants must have the legal right to work in Malaysia. Visa sponsorship is not available.
- 1–4 years of experience in AI/ML engineering with hands-on production experience in agentic or LLM-based systems.
- Demonstrated production experience with LangGraph and/or CrewAI.
- Experience integrating GPT Vision or equivalent for image and document understanding.
- Proficiency in Python; comfortable reading JavaScript.
- Experience with LLM APIs (OpenAI API, Claude API), function calling, tool use, and structured outputs.
- Strong prompt engineering skills, including system prompts, chain-of-thought, ReAct patterns, and output formatting.

- Experience with LangChain or LlamaIndex for knowledge-base construction.
