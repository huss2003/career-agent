We are seeking a seasoned Senior Full-Stack Python Engineer with 5+ years of experience to design, build, and scale robust web applications. In addition to core full-stack capabilities, you will help us bridge the gap between traditional software engineering and next-generation AI features.

The ideal candidate is a Python expert who is comfortable architecting scalable backends, building intuitive frontends, and has a foundational, working knowledge of Generative AI (e.g., integrating LLMs, prompt engineering, or using AI APIs) to help us inject smart capabilities into our product ecosystem.

**Key Responsibilities:**

· Backend Development: Design, develop, and maintain robust, scalable, and secure server-side logic using Python frameworks (FastAPI, Django, or Flask).

· Frontend Integration: Create highly responsive, user-friendly UI components using modern JavaScript frameworks (React.js, Vue.js, or Angular).

· GenAI Implementation: Integrate Generative AI capabilities into existing workflows, utilizing LLM APIs (OpenAI, Anthropic, or AWS Bedrock), managing prompt design, and working with vector databases for basic RAG (Retrieval-Augmented Generation) setups.

· Database & Architecture: Design optimal database schemas (SQL/NoSQL), write efficient queries, and implement caching layers to ensure low-latency application performance.

· CI/CD & Cloud: Deploy and manage applications within cloud environments (AWS/GCP/Azure), containerizing applications using Docker, and maintaining automated deployment pipelines.

· Mentorship & Best Practices: Lead code reviews, enforce clean architectural patterns, write comprehensive unit/integration tests, and mentor junior-to-mid-level engineers.

**Must-Have Skills:**

· Deep expertise in at least one major Python web framework (preferably FastAPI or Django).

· Strong understanding of asynchronous programming in Python (asyncio) and building RESTful or GraphQL APIs.

· Strong proficiency in JavaScript/TypeScript and hands-on production experience with React.js, Vue.js, or Next.js.

· Solid understanding of state management (Redux, Context API, Vuex) and modern CSS styling frameworks (Tailwind CSS, Styled Components).

· Practical experience consuming LLM APIs and designing effective system prompts.

· Proficiency with relational databases (PostgreSQL, MySQL) and NoSQL solutions (MongoDB, Redis).

· Solid experience with Docker and cloud services (specifically AWS services like EC2, Lambda, or ECS).

· Experience with Git and modern CI/CD tools (GitHub Actions, GitLab CI).

**Nice to Have:**
