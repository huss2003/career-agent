We’re looking for a Software Engineer to help build Leasing AI, a conversational product that helps prospective residents explore communities, check availability and pricing, create guest cards, and schedule tours across chat, SMS, and email.

You’ll help modernize leasing workflows by contributing to the services, integrations, and LLM-powered workflows behind them, from design and implementation through testing and production support. This is a hands-on role where strong engineering technical skills, along with AI, meet the fast-moving world of LLM-powered applications.

### Responsibilities will include:

- Deliver features across design, implementation, testing, release, and production support.
- Contribute to AI agent workflows, including intent handling, tool use, conversation context, multi-step tasks, follow-up questions, and escalation.
- Develop and maintain MCP tools with clear contracts, input validation, and reliable error handling.
- Build and maintain reliable services, MCP tools, agent behaviors, and integrations for leasing workflows such as property information, availability, pricing, lead management, and tour scheduling.
- Write automated tests and contribute to agent evaluations that assess workflow behavior and response accuracy.
- Investigate issues using logs, metrics, and traces; help improve performance, reliability, and customer experience.
- Follow security and data-handling standards, including tenant isolation and appropriate handling of personal information.
- Participate in code reviews and collaborate with Product, SDET, platform, and domain teams to deliver maintainable solutions.
