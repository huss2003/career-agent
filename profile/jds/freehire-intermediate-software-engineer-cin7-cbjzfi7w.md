## **How you'll make an impact:**

At Cin7, we are transforming the way businesses manage inventory, sales, and operations to make it cheaper, faster, and easier for businesses all over the world to get their products into their customers’ hands.

We’re looking for an Intermediate Software Engineer to join our engineering team and take on meaningful ownership of features in our cloud-based SaaS inventory management software. This role focuses on .NET development across .NET Framework, .NET, and ASP.NET MVC applications, with frontend work using JavaScript, HTML, and CSS. You’ll work independently on well-defined features, contribute to design decisions, and use AI tools to build and ship code faster while maintaining high quality.

**This position requires that you reside in Ahmedabad or Pune, India.**

### What you'll do:

- Design, build, and maintain features in our cloud-based SaaS inventory management software using .NET technologies.
- Work across the application, database, and frontend layers, including implementing API-driven features, writing and optimizing SQL queries, making UI updates, and working with forms and page layouts.
- Use AI coding assistants and agentic tools such as GitHub Copilot, Claude Code, or Cursor as part of your daily workflow for code generation, debugging, test writing, and code review, while maintaining full ownership of the code you ship.
- Collaborate with product managers, designers, and developers to define requirements, scope work, and deliver solutions.
- Write and maintain unit and integration tests to keep features reliable as they evolve.
- Review code from peers for quality, maintainability, and adherence to coding standards, providing constructive feedback.
- Identify and resolve performance issues and bugs in existing code.
- Share knowledge, provide guidance to less experienced developers, and contribute to a collaborative engineering environment.
- Explore where AI can add value to our product and contribute to building AI-powered capabilities.

### What you'll bring:

- A bachelor’s degree in Computer Science, Engineering, or a related field, or equivalent professional experience.
- 2–4 years of professional software development experience, with hands-on experience working on production systems.
- Strong proficiency in C# and .NET, including ASP.NET MVC, .NET Framework, or .NET web applications and APIs.
- Solid experience with SQL Server, including writing and optimizing queries, and working with stored procedures and indexes.
- Working knowledge of JavaScript, HTML, and CSS, including DOM manipulation, form validation, and working with API responses.
- Understanding of web fundamentals, including HTTP, REST APIs, and the request/response lifecycle.
- Experience writing unit and integration tests and using Git for version control.
- Hands-on experience using AI tools in professional development work, such as coding assistants or agentic workflows, and a good sense of when to rely on them and when to verify their output.
- Strong written and verbal communication skills and a collaborative approach to teamwork.
