**Data Platform Engineer (Full Stack)**

At Johnson Controls, you will help build the data platform behind OpenBlue, our smart-building platform. In this role, you will build the services, APIs, and user interfaces that put trusted building and energy data in the hands of the applications and people who rely on it.

**Role Overview**

We are looking for a full-stack Data Platform Engineer with 3+ years of experience to build data-serving APIs, platform tooling, and React front ends on the OpenBlue Data Platform (OBDP). You will work across .NET or Java back-end services and the streaming and lakehouse stack (Kafka, Flink, Spark, Apache Iceberg, and Snowflake) alongside senior engineers. This is a hands-on role where you will own well-scoped features end to end, from UI to data, and take on more design ownership over time.

**Key Responsibilities**

- Develop back-end services and data-serving APIs (REST and GraphQL) in .NET (C#) or Java.
- Build and maintain React and TypeScript front ends for platform tooling, data management, and operational views.
- Integrate services with Kafka, Flink, and Spark pipelines and with Iceberg, Snowflake, and PostgreSQL data stores.
- Write unit, integration, and functional tests and contribute to CI/CD pipelines.
- Fix production defects and support SIT, UAT, and deployments.
- Deploy services on AKS and set up monitoring and alerting for the features you own.

**How You Will Do It**

- Own the outcome with accountability by delivering well-tested features and following through on commitments.
- Stay close to work by understanding how users and downstream applications use the data and tools you build.
- Look for root causes, improve continuously, and raise issues with candor.
- Work as one team by partnering with engineers, QA, UX, and product, sharing context, and asking for help early.
- Use clear documentation and disciplined engineering practices to support consistency and handoffs.

**Qualifications**

- Bachelor's degree in computer science, Information Technology, Engineering, or a related field.
- 3+ years of experience in full-stack software engineering.
- Professional experience building front ends with React and TypeScript (or JavaScript), HTML, and CSS.
- Professional back-end experience in .NET (C#) or Java, including REST API design.
- Solid SQL skills and experience working with relational databases.
- Working knowledge of data platforms, with exposure to at least one of Kafka, Flink, Spark, Iceberg, or Snowflake, and eagerness to learn the rest.
- Experience with Git, code review, and agile/Jira workflows.
- Hands-on AI-assisted development with Claude Code, GitHub Copilot, or similar, with a critical eye for generated code.

**Nice to Have**

- GraphQL API design experience.
- Exposure to Trino, PostgreSQL, TimescaleDB, or HBase.
- Experience with Apache Airflow.
- Experience with Docker, Kubernetes, AKS, and Helm.
- Azure experience.
- Experience with time-series or IoT data.
- UI component libraries, design systems, or data visualization libraries.
