We are currently seeking an experienced professional to join our team in the role of Consultant Specalist

In this role you will:

- Design, build and deploy production-grade AI/ML solutions including LLM-powered applications, agentic workflows and intelligent automation systems
- Develop and optimise LLM applications using LangChain, LiteLLM, Langraph and other generative AI libraries including model evaluation, selection and fine-tuning
- Integrate third-party APIs, cloud AI services and custom models, building robust API layers and middleware for AI/ML systems
- Implement prompt engineering strategies including few-shot prompting, chain-of-thought techniques and retrieval-augmented generation (RAG) patterns
- Build evaluation frameworks and testing pipelines covering model performance, bias detection, fairness and business impact with production metrics and monitoring
- Build and maintain vector databases for semantic search, similarity matching and RAG systems
- Implement MLOps practices including model versioning, experiment tracking, CI/CD for ML models, A/B testing and canary deployments
- Monitor and optimise AI/ML systems in production including model drift, latency, cost and user satisfaction with retraining pipelines and automated model updates

To be successful in this role, you should meet the following requirements:

- Bring substantial hands-on experience developing and deploying production-grade AI/ML systems
- Demonstrate expert-level Python skills including data structures, algorithms and production software engineering best practices
- Apply deep understanding of machine learning fundamentals including transformers and modern deep learning architectures
- Build with LLM APIs such as OpenAI, Google Gemini, Anthropic Claude and Meta Llama including fine-tuning and inference optimisation where needed
- Use LLM frameworks such as LangChain, LiteLLM, Langraph or similar for orchestration and agentic systems
- Implement RAG systems including document chunking, embedding strategies, semantic search and reranking
- Build with vector databases and embeddings including solutions such as Pinecone, Weaviate, Milvus, Chroma, Qdrant or Cloud Firestore vector search
- Establish production engineering practices for AI systems including testing, error handling, logging, monitoring, CI/CD and operational support. Apply responsible AI, security standards and regulatory requirements including bias audits and fairness assessments
