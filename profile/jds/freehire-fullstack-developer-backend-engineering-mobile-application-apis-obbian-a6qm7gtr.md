**Job Description Fullstack Developer**

**Backend Engineering, Mobile Application APIs, Web & E-Commerce Development, AI Integrations - MANDATORY**

Role Overview

We are looking for experienced Fullstack Developers with strong expertise in backend engineering, mobile application API development, web application development, e-commerce and marketplace platforms, AI integrations and scalable cloud-based systems.

The candidate will be responsible for designing, developing and maintaining robust backend services for Android and iOS mobile applications, developing web applications using Next.js, building scalable e-commerce and marketplace solutions, implementing AI-powered integrations, developing RAG pipelines, automating business workflows and managing production deployments.

The ideal candidate should possess strong system design and architectural capabilities, with experience building secure, scalable, high-performance applications capable of handling large volumes of users, transactions, concurrent requests and data.
