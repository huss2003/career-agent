## **How you'll make an impact:**

At Cin7, we are transforming the way businesses manage inventory, sales, and operations to make it cheaper, faster, and easier for businesses all over the world to get their products into their customers’ hands.

We’re looking for a Junior Software Engineer to join our engineering team and grow with us. This role focuses on .NET development across .NET Framework, .NET, and ASP.NET MVC applications, with some frontend work using JavaScript, HTML, and CSS. You’ll work on our cloud-based SaaS inventory management software, learn from experienced engineers, and use AI tools to help you work faster and build stronger skills.

**This position requires that you reside in Ahmedabad or Pune, India.**

### What you'll do:

- Build and maintain features in our cloud-based SaaS inventory management software using .NET technologies.
- Work across the application, database, and frontend layers, including writing API-driven features, writing SQL queries, making UI updates, and working with forms and page layouts.
- Use AI tools to support code generation, debugging, testing, and code review, while ensuring you understand, validate, and take responsibility for the code you contribute.
- Collaborate with product managers, designers, and other developers to understand requirements and deliver solutions.
- Write and maintain unit and integration tests for the features you build.
- Participate in code reviews by reviewing other devs' code, learning from feedback, and gradually developing the ability to identify potential issues and suggest improvements.
- Learn from senior engineers and grow toward taking on more complex, end-to-end work over time.
- Participate in the exploration and implementation of AI-powered features alongside senior engineers.

### What you'll bring:

- A bachelor’s degree in Computer Science, Engineering, or a related field, or equivalent professional experience.
- Some practical experience with software development through internships, personal projects, university projects, or professional work.
- Hands-on experience with C# and .NET, including ASP.NET MVC or .NET Framework applications.
- Familiarity with AI-powered development tools and an interest in using them to improve productivity and code quality.
- Working knowledge of SQL, including writing queries and working with relational databases such as SQL Server.
- Understanding of HTML, CSS, and JavaScript, including DOM manipulation and working with API responses.
- Familiarity with web fundamentals, including HTTP, REST APIs, and client-server communication.
- Basic understanding of unit testing and version control with Git.
- Strong communication skills and a willingness to ask questions and learn.

### It's a nice to have if you bring:
