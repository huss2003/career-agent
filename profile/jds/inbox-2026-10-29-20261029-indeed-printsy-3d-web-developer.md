About Printsy

Printsy is an Australian startup in the 3D printing industry, developing premium-quality filaments and a growing library of original 3D printable models.

We're looking for an Interactive 3D Web Developer to build browser-based 3D configurators and model customisation tools that allow users to create, customise and export 3D-printable models.

Examples include custom cookie cutter makers, parametric vase generators and other interactive tools where users can modify shapes, dimensions, text and patterns, preview changes in real time, and export their designs for 3D printing.
