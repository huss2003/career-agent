### Key Responsibilities:

- Design, develop, and execute UI performance testing strategies using Playwright or Selenium with Artillery to simulate load, measure response times, and optimize user experience.
- Write maintainable automated tests in JavaScript or Java, leveraging HTML, CSS, SQL queries for data validation, and API testing tools for end-to-end coverage.
- Integrate performance and API tests with CI/CD pipelines, analyze results, debug bottlenecks, and perform root cause analysis for failures.
- Collaborate with developers and product teams to triage issues, refine test data strategies, and drive quality metrics.
- Quickly learn and test complex software solutions, adapting to rapidly evolving AI-driven features.

### Skills & Experience:

- 2-3 years of experience as QA Engineer or Automation Tester, with hands-on UI automation using Playwright or Selenium.
- Proficiency in JavaScript or Java for test scripting, plus solid knowledge of HTML, CSS, SQL, and API testing.
- Experience with Artillery for load and performance testing on UI applications.
- Familiarity with automation runs analysis, triaging failures, fixes, and reporting in fast-paced environments.
- Daily usage of AI tools like Cursor, Claude, or other LLM models to accelerate coding, debugging, and test development.

### Preferred Skills:

- Complete end-to-end automation experience, including Playwright or Selenium with JavaScript or Java, plus basic cloud technologies like AWS or others.
- Knowledge of monitoring tools like Datadog for performance metrics and observability.
- Background in performance optimization, CI/CD tools like Jenkins, or reporting with Allure.
- Exposure to Docker and role-based permission testing.
