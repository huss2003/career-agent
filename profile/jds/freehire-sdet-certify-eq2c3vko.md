**Job description:**

We are looking for an AI-first Software Development Engineer in Test (SDET) to help us build reliable, scalable, and high-quality software.

This role goes beyond traditional QA and test automation. You will leverage AI-assisted engineering and agentic workflows to accelerate test development, improve test coverage, automate quality checks, and identify performance and scalability issues.

You will work closely with developers, product managers, and engineering leaders to embed quality throughout the software development lifecycle.

We expect you to think like a software engineer, automate like an SDET, and use AI as a force multiplier.

**Key Responsibilities:**

- Adopt AI-assisted and agentic approaches across the testing lifecycle.
- Use AI coding agents to generate, execute, debug, and maintain automated tests.
- Build AI-assisted workflows for test case generation from product specifications and acceptance criteria.
- Explore agentic testing approaches that can independently execute workflows, identify failures, and report defects.
- Use AI to analyze test failures, identify patterns, and suggest potential root causes.
- Continuously identify opportunities to reduce manual effort through AI and automation.
- Build and maintain scalable automation frameworks for UI, API, integration, and end-to-end testing.
- Develop reusable test components and automation libraries.
- Automate critical business workflows and regression suites.
- Integrate automated testing into CI/CD pipelines.
- Use Playwright, Cypress, Selenium, or equivalent frameworks.
- Design and execute load, stress, spike, and endurance tests.
- Simulate real-world traffic, concurrent users, and high-volume API requests.
- Establish performance benchmarks and service-level objectives.
- Identify bottlenecks across APIs, databases, microservices, and infrastructure.
- Use tools such as k6, JMeter, Locust, or Gatling.
- Analyze latency, throughput, resource utilization, and error rates.
- Work with developers to identify and resolve performance bottlenecks.
- Validate application behavior as traffic, data volume, and workloads increase.
- Identify scalability limitations across distributed systems.
- Test asynchronous workflows, queues, event processing, retries, and failure recovery.
- Evaluate database performance and query efficiency under load.
- Identify resource constraints and potential points of failure.
- Contribute to capacity planning and reliability improvements.
- Work with developers and product managers to identify quality risks early.
- Participate in technical design and code reviews.
- Define quality gates and automation standards.
- Build a culture where quality is everyone's responsibility.
