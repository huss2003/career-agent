About the role

We're building software where AI agents do real work inside the tools teams already use, starting with Slack. You'll be one of the first engineers, owning the backend, the infrastructure it runs on, and the security of both.

What you'll do

- Design and build backend services, APIs, and agent workflows that are reliable in production
- Build and ship product features across the stack as needed
- Own our cloud infrastructure on GCP: VMs, networking, IAM, and cost control
- Set up CI/CD, infrastructure as code, and isolated dev/staging/prod environments
- Build logging, monitoring, and alerting so we catch problems before users do
- Secure the platform: secrets management, least-privilege access, credential handling, and audit trails for agents that act on users' behalf
- Threat-model agent behavior (prompt injection, tool misuse, data leakage) and put guardrails in place
- Integrate third-party APIs (Slack, Notion, others) with secure OAuth and webhook handling

Must have

- 4+ years of backend engineering (Python and/or TypeScript/Node)
- Hands-on DevOps: Linux, Docker, CI/CD, Terraform or similar
- Production experience on GCP (or AWS/Azure with a fast ramp-up)
- Solid security fundamentals: authn/authz, secrets management, network hardening, secure API design
- Experience with databases (Postgres or similar) and designing for reliability
- Bias to ship, plus clear written communication in an async team

Nice to have

- Experience with LLM APIs, tool use, or agent frameworks
- Security background (AppSec, SOC 2 or compliance prep, pen-testing, incident response)
- Kubernetes or serverless (Cloud Run) experience
- Prior startup or founding-team experience
