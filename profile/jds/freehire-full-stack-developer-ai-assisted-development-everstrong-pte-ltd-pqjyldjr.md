**Full Stack Developer (AI-Assisted Development) – We're Hiring!**

Join our team of skilled developers who code well and build faster with AI. You will use tools like Claude Code, Codex and Cursor to ship features, tools, automations and websites for our e-commerce and local retail service brands, with everything tested, secure and reliable before it goes live.

IMPORTANT: We value responsible, self-motivated people who take ownership of their work and can deliver quality work with minimal supervision.

**Job Scope:**  
• Use AI coding tools (such as Claude Code, Codex or Cursor) daily to plan, write, test and review code  
• Build AI-powered tools, automations and features using LLM APIs (such as Claude or OpenAI), for example content generation, data clean-up, reporting and workflow automation  
• Build and maintain features, custom apps and integrations for our e-commerce brands across Shopify, Shopee, Lazada, TikTok Shop and Amazon  
• Build and update brand websites and landing pages (Shopify, Wix and WordPress), including outlet location pages, pricing pages and campaign pages  
• Set up enquiry and sign-up forms that feed into our CRM and WhatsApp, plus tracking and SEO basics (Google Analytics, Search Console, ad pixels)  
• Make every page fast, mobile-friendly and easy to use, and create simple page visuals with AI tools using our design guidelines  
• Review and test all code, AI-written or not, before it goes live: staging first, code review, and no secrets or keys in code  
• Write clear documentation so non-technical teammates can use and update what you build

**You should have:**  
• At least 3 years of full stack experience: front end (HTML, CSS, JavaScript or TypeScript, React or similar) and back end (Node.js, Python or PHP)  
• Daily, hands-on use of AI coding tools, and the judgement to check, test and correct their output  
• Experience building features or automations with LLM APIs (Anthropic, OpenAI or similar)  
• Experience with REST or GraphQL APIs, SQL databases and a clean Git workflow  
• A good eye for clean, mobile-friendly pages  
• Clear written English, and the ability to explain technical trade-offs to non-technical teammates  
• A plus: Shopify development (Liquid, Admin API), and experience with Wix or WordPress

You do not need to be a graphic designer. Visuals can be created with AI tools using our design guidelines.
