## About the Opportunity

Pragmatike is recruiting on behalf of a global enterprise cybersecurity company building a new generation of products to secure **AI agents, LLM-powered applications, and the data they access**.

The Endpoint Security team extends these controls directly to user devices, detecting AI tools and agents running on laptops and workstations, monitoring their access to local data, and enforcing security policies where traffic never reaches a gateway.

You'll build the **Go-based endpoint components and backend services** that power this system.

This role is suited to a **systems-minded engineer** who is comfortable working close to the operating system and understands the challenges of performance, resource usage, reliability, and software running across machines you don't control.

## What You'll Do

- Design and build Go agents and backend services for endpoint visibility and security enforcement across **Windows, macOS, and Linux**.
- Detect AI applications, local models, browser-based agents, and IDE assistants, and monitor their interaction with sensitive files and processes.
- Build backend services for endpoint fleet management, including configuration, policy distribution, telemetry ingestion, and health monitoring.
- Optimize endpoint software for **low resource usage, reliability, safe updates, and resilience on unreliable networks**.
- Collaborate with security researchers on detection logic and with platform teams on telemetry and data pipelines.
- Contribute to cross-platform testing, code signing, release engineering, and production readiness.
- Use AI-assisted development workflows to accelerate implementation, testing, debugging, and problem-solving.
