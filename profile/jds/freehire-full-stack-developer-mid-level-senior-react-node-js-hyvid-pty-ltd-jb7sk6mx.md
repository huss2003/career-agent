## About the Opportunity

We are looking for talented and adaptable **Mid-Level and Senior Full Stack Developers** to join our growing team and support an Australian software group specialising in B2B asset management and industrial software solutions.

Our client is expanding its portfolio of software products, including established maintenance management applications and new solutions involving asset tracking, equipment management, and financial planning across the asset lifecycle.

This is an exciting opportunity to work on both established software platforms and the development of new products, with a strong focus on building features, solving technical challenges, and contributing to the evolution of modern software applications.

You'll work closely with an experienced technical leadership team and other developers, taking ownership of features across the full technology stack—from front-end interfaces and back-end services to databases, integrations, testing, and deployment.

We're considering both **Mid-Level and Senior Developers**, with flexibility around the final mix of experience. We're particularly interested in developers who combine strong coding fundamentals with effective use of modern AI-assisted development tools, while maintaining full understanding and ownership of their work.

## Key Responsibilities

## 1. Full Stack Application Development

- Design, develop, maintain, and improve modern web applications using React, TypeScript, JavaScript, Node.js, and related technologies.
- Develop responsive and maintainable front-end components and user interfaces.
- Build and maintain back-end services, REST APIs, and database integrations.
- Work with relational databases, including MySQL or similar SQL technologies.
- Take ownership of assigned features from development and testing through deployment and ongoing support.
- Develop new functionality for existing platforms and contribute to the development of new software products.
- Troubleshoot and resolve technical issues across front-end, back-end, API, and database layers.

## 2. Technical Design, Code Quality & Collaboration

- Collaborate with the Technical Lead and development team on technical requirements, implementation approaches, and feature delivery.
- Follow established architecture, coding standards, and development practices.
- Participate in code reviews, pull requests, and constructive technical discussions.
- Write clean, secure, maintainable, and well-documented code.
- Apply secure coding practices across authentication, authorisation, input validation, API security, dependencies, and data access.
- Identify technical issues, risks, and opportunities to improve application performance and reliability.
- Maintain relevant technical documentation, API documentation, and implementation notes.

## 3. AI-Assisted Software Development

- Use modern AI-assisted coding tools, such as Cursor, Claude Code, OpenAI Codex, or similar technologies, where appropriate.
- Independently review, validate, and understand AI-generated code before implementation.
- Ensure AI-assisted solutions meet expected standards for accuracy, security, performance, and maintainability.
- Apply sound technical judgment when determining when and how AI tools should be used.
- Demonstrate the ability to explain technical decisions and the underlying code, regardless of whether AI assistance was used.

## 4. Mobile Development & Broader Technical Support

- Contribute to React Native mobile application development and maintenance where required.
- Assist with mobile application functionality, integrations, and troubleshooting.
- Support testing, release preparation, deployment, and production issue resolution.
- Collaborate on broader technical responsibilities, including cloud deployment, automated testing, and development workflows.
- Work across multiple aspects of the application stack as required by project priorities.

**React Native experience is particularly valuable**, as we're looking to strengthen mobile development capability across the expanding team.

## 5. Additional Responsibilities for Senior Developers

Senior-level candidates will also be expected to:

- Contribute more extensively to technical design, architecture, and implementation decisions.
- Independently manage complex features and technical deliverables.
- Provide technical guidance and constructive feedback to other developers.
- Support and mentor less-experienced team members where required.
- Identify and address architectural, security, performance, and maintainability concerns.
