### Position Summary

The Software Engineer (.NET) designs, develops, and maintains features within Onit's AI-driven legal operations platform, spanning enterprise legal management, matter management, spend management, and contract lifecycle management. As a member of the Product Engineering team, this role builds reliable business applications using C#, .NET, and Microsoft SQL Server, working closely with Product Managers, QA Engineers, UX Designers, and fellow developers in an Agile environment. The role also uses AI-assisted development tools to improve productivity and software quality, and offers strong opportunities to grow technical depth under the guidance of senior engineers.

### Key Responsibilities

• Application Development: Design, develop, test, and maintain software applications using C# and .NET, writing clean, efficient, maintainable, and well-documented code.

• Database Development: Develop and optimise SQL queries, stored procedures, and database operations in Microsoft SQL Server.

• Troubleshooting & Quality: Troubleshoot, debug, and resolve application issues in a timely manner, and participate in code reviews to continuously improve development practices.

• Agile Delivery: Collaborate with Product Managers, QA Engineers, UX Designers, and developers across the SDLC, participating in sprint planning, daily stand-ups, and retrospectives.

• Source Control: Use GitLab and Git-based workflows (branching, merging, merge requests) for source code management and version control.

• AI-Assisted Development: Leverage AI-assisted development tools to improve coding efficiency, testing, documentation, and problem-solving.

• Documentation & Knowledge Sharing: Contribute to technical documentation and team knowledge-sharing activities.

### Required Skills

• 2+ years of hands-on software development experience using C# and .NET; Bachelor's degree in Computer Science, Information Technology, Engineering, or a related field.

• Strong proficiency in C# with a solid understanding of object-oriented programming (OOP) concepts, and strong coding, debugging, and problem-solving skills.

• Experience with Microsoft SQL Server, including SQL queries, stored procedures, CRUD operations, database design concepts, and relational database principles.

• Experience using Git for source control, including branching and merging, pull/merge requests, and version control best practices (GitLab preferred).

• Understanding of Agile/Scrum methodologies and software development lifecycle (SDLC) practices.

• Familiarity with AI-powered development tools (e.g., GitHub Copilot, Claude, ChatGPT) for code generation, testing, and documentation, with the judgment to review and validate AI-generated code.

• Strong analytical and troubleshooting skills, attention to detail, good verbal and written communication, and the ability to work effectively in a collaborative team.

### Preferred Qualifications

• Experience with third-party UI frameworks such as DevExpress.
