### Accountabilities

- Design, develop, and operationalize AI-powered applications, copilots, and autonomous agents tailored to cybersecurity use cases and enterprise security requirements.
- Build retrieval-augmented generation (RAG) solutions that leverage enterprise knowledge repositories, security data, and contextual information to improve the accuracy and relevance of AI-generated insights.
- Develop integrations using the Model Context Protocol (MCP) and APIs to connect AI agents with security tools, enterprise platforms, and operational workflows.
- Engineer secure, scalable, and maintainable AI services using modern software engineering, DevOps, and deployment practices.
- Enhance self-hosted AI infrastructure, model-serving environments, and AI observability capabilities to support reliable enterprise-scale deployments.
- Develop and automate security workflows that improve analyst productivity, reduce manual effort, and streamline cybersecurity operations.
- Collaborate with security operations, risk, product security, vulnerability management, and threat intelligence teams to identify business needs and deliver practical AI-driven solutions.
- Implement and optimize agentic workflows and multi-agent systems to support complex security tasks and improve operational decision-making.
- Apply secure AI design principles to mitigate risks such as prompt injection, model misuse, sensitive data leakage, and unauthorized agent actions.
- Establish and maintain engineering standards for CI/CD, version control, automated testing, code quality, monitoring, and production readiness.
- Troubleshoot technical issues, evaluate emerging AI technologies, and continuously improve the performance, security, scalability, and reliability of AI solutions.
