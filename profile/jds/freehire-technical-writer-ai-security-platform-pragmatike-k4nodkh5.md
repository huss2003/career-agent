## About the Opportunity

Pragmatike is recruiting on behalf of a global enterprise cybersecurity company building a new generation of products to secure **AI agents, LLM-powered applications, and the data they access**.

As the AI security platform moves toward general availability, customers, partners, and internal teams need documentation that is **accurate, technically rigorous, and easy to act on**.

You'll own the documentation ecosystem across product guides, API references, deployment and integration documentation, and release materials, working closely with **Go engineers, Product Managers, and Support**.

We're looking for a Technical Writer who is comfortable reading code and API specifications, can explain complex security and infrastructure concepts clearly, and uses AI tools to work more efficiently without compromising technical accuracy.

## What You'll Do

- Own end-user, administrator, and API documentation for the AI security platform, from initial structure through ongoing maintenance.
- Create deployment and integration guides for gateway, endpoint, cloud discovery, and platform components, including **code samples and configuration references**.
- Write release notes and in-product help, and maintain documentation standards and style guidelines.
- Work directly with engineers to generate and maintain API documentation from **OpenAPI and protobuf definitions**, keeping documentation aligned with product releases.
- Review technical examples and documentation for accuracy, consistency, and usability.
- Gather feedback from customers and Support to identify documentation gaps and improve clarity.
- Use AI tools to draft, review, update, and maintain documentation at scale while ensuring all technical content is properly validated.

## What We're Looking For

- **4+ years** of technical writing experience for developer- or administrator-facing B2B software.
- Ability to read **Go, Python, OpenAPI, and protobuf** well enough to accurately document APIs, configurations, and code examples.
- Experience with **docs-as-code workflows**, including Markdown, Git, static site generators, and CI-based publishing.
- Strong understanding of cybersecurity, cloud infrastructure, or related technical concepts, or a demonstrated ability to learn complex technical domains quickly.
- Excellent written English with the ability to explain complex concepts clearly to both technical and non-technical audiences.
- Practical experience using **AI writing and coding assistants**, combined with a rigorous process for reviewing and validating their output.
- Comfortable collaborating with distributed engineering and product teams across time zones.
- Strong ownership and attention to technical detail.

## Nice to Have

- Experience with API documentation and publishing tools such as **Redocly, Stoplight, Docusaurus**, or equivalent.
