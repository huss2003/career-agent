About the role

We are looking for a hands-on Senior Test Automation Engineer to own Playwright + Python UI automation for our web applications. You will build maintainable pytest-based frameworks, run them in CI on Azure Pipelines, keep the suite fast and reliable, and mentor junior engineers.

What you will do

- Design and extend a Playwright + Python framework on pytest, using Page Object Model, fixtures and reusable utilities.
- Automate end-to-end UI tests from user stories and acceptance criteria, across Chromium, Firefox and WebKit.
- Build stable locator strategies and keep the flaky-test rate under 2%.
- Integrate suites into Azure Pipelines with parallel runs (pytest-xdist) and useful failure artifacts (traces, screenshots, videos).
- Track tests and defects in Azure Boards and Test Plans, linked to user stories for traceability.
- Triage failures daily and report coverage, pass rate, execution time and flakiness each sprint.
- Review peers' automation code and mentor 13 junior engineers.

What you bring

- **Playwright (Python):** built or substantially extended a framework; strong with the sync/async APIs, auto-waiting, locators, browser contexts, network interception/mocking, auth via storage state, and Trace Viewer.
- **Python:** OOP, type hints, decorators, context managers, exception handling, virtual environments; clean, modular code checked with Ruff or Flake8 and Black.
- **pytest:** fixtures and scopes, conftest.py, markers, parametrization, pytest-playwright plugin, pytest-xdist, HTML/JUnit reporting.
- **Azure DevOps and Git:** Git in Azure Repos (branching, pull requests, code reviews, conflict resolution); YAML Pipelines, Boards and Test Plans; publishes test results to pipelines.
- **Testing fundamentals:** test pyramid, test design techniques, risk-based prioritisation, basic SQL, Agile/Scrum.
- Clear communication and ownership; can explain a failure to a developer and a risk to a product owner.

Good to have

- API testing with Python (requests, httpx or Playwright's APIRequestContext).
- GitHub and GitHub Actions workflows.
