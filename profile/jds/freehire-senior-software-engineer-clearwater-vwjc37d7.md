## Frontend focus

**Title:** Senior Software Engineer – Fullstack AI (Frontend Focus)

**Location:** Pune (M.H)

**Experience:** 4+ years in software engineering, including 1+ year building AI-powered user experiences in production

### About the role

You'll own the experience layer of Clearwater's AI-enabled security products. This is a hands-on role: you'll build fast, accessible interfaces for agent-driven workflows and write the backend glue they need. You'll work with design, product, and backend engineers from concept to production.

### What you'll do

- Build production web applications with React and TypeScript, with strong performance, accessibility, and testing
- Design AI-native interfaces: streaming responses, tool-call and agent-step visibility, approval and human-in-the-loop controls, citations, and graceful failure states
- Build and maintain a shared component library and design system
- Write the backend-for-frontend layer in Python or Node: APIs, auth, session handling, and streaming endpoints (SSE/WebSockets)
- Instrument user-facing AI features with analytics, tracing, and feedback capture to improve quality
- Use AI coding tools and agents to speed up UI development, testing, and review, and help the team do the same
- Review code, set frontend standards, and mentor engineers

### Must have

- 4+ years of professional software engineering with a frontend-leaning full-stack record
- Strong JavaScript/TypeScript and React (Next.js or similar), with solid HTML/CSS and browser fundamentals
- 1+ year building UI for LLM or agent features that reached production (streaming, chat or workflow UIs, state handling)
- Working backend ability in Python or Node, including REST/GraphQL APIs and a relational database
- Frontend testing and quality practice: unit, integration, end-to-end, and performance and accessibility checks
- Working knowledge of Docker, CI/CD, and one major cloud

### Nice to have

- Experience building dashboards or analyst-style tools for security, healthcare, or compliance-driven products
- Familiarity with agent protocols and tooling such as MCP, and with how agents call tools
- Data visualization experience for complex, high-volume data
- Experience with design systems and Storybook
- Open-source contributions or public UI projects

### First 12 months

- Ship production features end to end with high quality and accessibility
- Deliver an agent-driven workflow UI that users adopt, with measurable task-completion or time-saved gains
- Establish the team's patterns for AI interface states, human approval steps, and frontend evals

### Why join

You'll have high ownership at an early-stage engineering site, direct exposure to leadership, and the chance to shape how security teams interact with AI agents.
