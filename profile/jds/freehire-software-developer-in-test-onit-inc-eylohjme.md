The Software Developer in Test (SDET) designs, builds, and maintains the automation frameworks that safeguard the quality of Onit's AI-driven legal operations platform, spanning enterprise legal management, matter management, spend management, and contract lifecycle management. Working within Pune R&D Engineering, this role develops UI, API, and integration test automation using Playwright and JavaScript, integrates it into Jenkins CI/CD pipelines, and drives automation best practices, test data strategy, and quality metrics across the team. Partnering closely with developers and product teams, the Senior SDET investigates complex failures, performs root cause analysis, and helps the team ship high-quality releases with confidence.

### Key Responsibilities

• Automation Frameworks: Design, develop, and maintain automation frameworks for UI, API, and integration testing.

• Test Development: Write maintainable automated tests using Playwright and API automation, with appropriate coverage of critical workflows, edge cases, and role-based permissions.

• CI/CD Integration: Integrate automation frameworks with Allure reporting, Jenkins, and CI/CD pipelines so tests run reliably on every build.

• Failure Analysis & Debugging: Analyse and triage automation runs, debug complex issues, perform root cause analysis, and drive fixes with development teams.

• Quality Practices: Drive automation best practices, test data strategy, and quality metrics, and report on quality trends to engineering leadership.

• Code Quality & Collaboration: Review and merge automation code changes in line with best practices, and partner with developers and product managers to build quality in from the start.

### Required Skills

• 3+ years of experience as an SDET or Automation Engineer in product-based, fast-paced environments.

• Strong programming skills in JavaScript (TypeScript a plus).

• Hands-on experience building and maintaining test automation with the Playwright framework, including UI and API automation.

• Working experience integrating automation frameworks with Allure reports, Jenkins, and CI/CD pipelines.

• Experience analysing automation runs, triaging failures, implementing fixes, and reporting results.

• Experience conducting code reviews and merging code changes while maintaining best practices and Git-based workflows.

• Working proficiency with AI tools (e.g., Claude, GitHub Copilot) to accelerate test creation, debugging, and failure analysis, with the judgment to review and validate AI-generated tests and code.

### Preferred Qualifications

- Working experience with Docker, CI/CD pipelines, and cloud platforms such as AWS.
- Exposure to security testing and role-based permission testing.Test LLM outputs for quality, consistency, safety, and hallucinations, and design evals with rubrics, run execution, and result interpretation.
- Build datasets for agents and MCP integrations, including edge and adversarial cases, and understand agentic workflows (planning, tool calling, step chaining).
- Nice to have: Python for building evaluation scripts, automating test pipelines, and analyzing results.
