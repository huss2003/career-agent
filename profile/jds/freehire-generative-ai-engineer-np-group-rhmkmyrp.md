**Senior Generative AI Engineer — Python / RAG / Agentic AI**

**India | Fully Remote | Full Time Contract | 6–12 Months | Up to $20 USD/hour**

We need an established hands-on Python/AI engineer with at least five years of commercial software, ML engineering or applied data-science experience, including at least two years personally developing commercial GenAI applications. You must have delivered applications into production and be able to explain your own implementation, evaluation and troubleshooting.

Experience limited to personal projects, AI-assisted coding, prompt engineering or recently adding LLM integrations will not meet this requirement.

**The work will involve:**

- Building Python services and APIs for GenAI applications.
- Developing RAG pipelines over documents and structured business data.
- Building agents that retrieve information, call tools and execute multi-step workflows.
- Integrating LLM applications with databases, APIs and enterprise systems.
- Evaluating answer quality, investigating failures and improving reliability.
- Deploying and supporting applications in cloud environments.

**Essential Experience:**

- At least five years of commercial experience in software engineering, ML engineering or applied data science, including substantial hands-on Python development.
- Around two years or more of commercial GenAI/LLM application development.
- Personal responsibility for significant components of at least one GenAI application used in production by business users or customers.
- Strong Python backend development, ideally FastAPI or a comparable API framework.
- Practical RAG experience covering ingestion, document processing, chunking, embeddings, vector retrieval and grounded answers.
- Commercial agent or workflow orchestration using LangGraph, LangChain or an equivalent framework, including custom Python implementations.
- SQL, structured and unstructured data, and external API integration.
- Experience testing LLM outputs, diagnosing retrieval or tool failures and implementing appropriate validation and access controls.
- Cloud deployment experience with AWS, Azure or GCP, plus Docker and version-controlled delivery.

**Useful additional experience:**

- Natural-language-to-SQL and conversational analytics.
- MCP servers and tool integration.
- Hybrid retrieval, reranking and retrieval evaluation.

- An earlier background in production ML, NLP, recommendation systems or predictive modelling.
