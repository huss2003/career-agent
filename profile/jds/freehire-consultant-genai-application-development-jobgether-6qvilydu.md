**This position is listed on behalf of a partner company, which manages all applications and next steps. Our partner is looking for a Consultant – GenAI Application Development based in India.**

This role offers the opportunity to design and deliver intelligent applications powered by generative AI and large language models. You will develop practical AI-driven solutions using Python, OpenAI technologies, and the Microsoft Azure ecosystem. Working across application development, AI workflow design, and cloud integration, you will help transform complex requirements into secure, scalable applications. You will build features such as intelligent chat interfaces, document question-answering systems, and automated content processing. The position combines hands-on engineering with modern AI frameworks, cloud deployment, and continuous improvement. You will collaborate within an Agile environment, taking ownership of development quality, deployment efficiency, and reliable delivery.

### Accountabilities

- Design, develop, and implement intelligent applications powered by large language models (LLMs), including GPT and Codex.
- Integrate OpenAI and Azure OpenAI APIs to deliver natural language processing capabilities such as summarization, classification, and conversational interfaces.
- Develop and optimize prompt-engineering solutions to improve the accuracy, relevance, and performance of AI-generated outputs.
- Use frameworks such as LangChain, Semantic Kernel, and Haystack to orchestrate models, manage memory, and enable tool usage.
- Build and deploy Python applications using Azure services, including Azure Functions, App Services, and Container Apps.
- Integrate Azure Cognitive Services, Azure OpenAI, Azure AI Search, Blob Storage, and Key Vault into application architectures.
- Implement secure cloud access through Managed Identities, service principals, and role-based access control (RBAC).
- Design AI workflows for document ingestion, information retrieval, and response generation.
- Implement token management, output parsing, response validation, and fallback mechanisms to ensure reliable LLM behavior.
- Secure API integrations and manage credentials and secrets through Azure Key Vault.
- Handle API-related concerns, including CORS, request throttling, exception management, and quota monitoring.
- Monitor model usage and API latency, identifying and addressing performance or capacity issues.
- Establish and maintain CI/CD pipelines using Azure DevOps or GitHub Actions to support efficient and consistent deployments.
- Maintain clean, modular, maintainable Python code and target at least 85% test coverage.
- Deliver reliable GenAI features, aiming for fewer than 5% functional defects.
- Maintain a target of 95% uptime while ensuring secure and appropriate use of Azure services.
- Support CI/CD-based releases with a target turnaround of fewer than two days per release.
- Participate actively in Agile ceremonies, collaborate with team members, and take full ownership of assigned sprint tasks.

- Bachelor's or master's degree in Computer Science, Artificial Intelligence, Machine Learning, Data Science, or a related discipline, or equivalent practical experience in Python and AI application development.
- Strong Python application development skills and the ability to build modular, production-ready solutions.

- Ability to design document ingestion, retrieval, and response-generation workflows.
- Understanding of API integration, error handling, throttling, CORS, monitoring, and quota management.
- Experience with CI/CD pipelines using Azure DevOps or GitHub Actions.
- Familiarity with Docker and containerized application deployment is preferred.
- Previous experience building LLM-powered chatbots, document question-answering solutions, or GenAI copilots is an advantage.
- Experience integrating Azure AI Search with OpenAI is preferred.
- Familiarity with Agile/Scrum methodologies and collaborative software delivery.
- Strong problem-solving, communication, ownership, and teamwork skills, with a focus on code quality and reliable delivery.
