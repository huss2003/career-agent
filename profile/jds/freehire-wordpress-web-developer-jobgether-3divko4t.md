We are looking for a detail-oriented WordPress Web Developer to build, update, and optimize websites for healthcare clients. In this role, you will recreate existing website designs with a strong focus on visual accuracy, usability, and responsive performance across desktop, tablet, and mobile devices. You will work with popular WordPress page builders to deliver high-quality web pages that align with established design guidelines and client expectations. You will also use AI-powered tools to accelerate development, troubleshoot issues, and improve workflow efficiency. This opportunity is ideal for a developer who combines solid front-end fundamentals with an eye for detail and a commitment to delivering polished digital experiences. You will work remotely in a practical, fast-paced environment where quality, communication, and continuous improvement are highly valued.

### Accountabilities:

- Build, update, and maintain WordPress pages using page builders such as Elementor, Divi, and Gutenberg.
- Recreate existing website designs as accurately as possible, ensuring consistency in typography, colors, spacing, layouts, and visual elements.
- Implement responsive designs that provide a seamless and consistent user experience across desktop computers, tablets, and mobile devices.
- Identify and resolve layout inconsistencies and styling issues using HTML and CSS.
- Leverage AI tools such as ChatGPT, Claude, and GitHub Copilot to assist with code generation, troubleshooting, problem-solving, and development efficiency.
- Apply basic search engine optimization (SEO) best practices when building and updating web pages.
- Optimize and edit images as needed to ensure appropriate presentation and performance across devices.
- Conduct quality assurance checks on completed work, identify visual or functional issues, and verify that pages meet design requirements before delivery.
- Follow basic web accessibility principles to improve website usability and accessibility where applicable.
- Communicate progress, clarify requirements, and collaborate with team members to deliver accurate, high-quality website updates for healthcare clients.

## Requirements:

- **1–3 years of hands-on WordPress development experience**, including building, editing, and maintaining website pages.
- Practical experience with at least two of the following WordPress page builders: Elementor, Divi, and Gutenberg.
- Good understanding of HTML, CSS, and responsive web design principles.
- Ability to reproduce existing website designs accurately, with strong attention to typography, spacing, colors, alignment, and layout details.
- Basic knowledge of SEO best practices and image editing or optimization.
- Comfortable using AI-powered tools such as ChatGPT, Claude, or GitHub Copilot to support coding, debugging, and daily development tasks.
- Strong visual attention to detail and the ability to identify and correct inconsistencies in website layouts.
- Good troubleshooting and problem-solving skills, with the ability to resolve common WordPress and front-end issues.
- Clear written and verbal communication skills, with the ability to understand instructions, ask relevant questions, and provide progress updates.
- Ability to work independently in a remote environment while managing tasks and maintaining consistent quality.
- Basic knowledge of WCAG accessibility guidelines is an advantage.
- Previous experience working on websites for U.S.-based clients is a plus.
