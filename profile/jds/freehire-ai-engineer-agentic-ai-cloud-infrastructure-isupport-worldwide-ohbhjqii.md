We are seeking a hands-on AI Engineer to design, develop, and deploy AI agents and intelligent automation solutions for enterprise applications who can contribute across the full development lifecycle, from AI agent architecture and backend development to infrastructure deployment, authentication, testing, and production maintenance.

The role involves working with large language models (LLMs), including both commercial and open-source models, with opportunities to fine-tune, customize, evaluate, and optimize models for specific business use cases.

The ideal candidate must have strong software engineering skills, experience working with Microsoft Azure infrastructure, and the ability to develop AI agents that integrate securely with enterprise systems such as Microsoft Teams, SharePoint, Outlook, and other Microsoft 365 services.

**Key Responsibilities:**

- AI Agent Development
  
  - Design, develop, and deploy AI agents capable of performing multi-step tasks and automating business workflows
  - Build agents using Microsoft Foundry (Azure AI Foundry), Azure AI Agent Service, and other agent frameworks such as LangGraph, Semantic Kernel, or similar technologies
  - Develop agent capabilities including tool calling, function execution, retrieval-augmented generation (RAG), memory management, and workflow orchestration
  - Integrate agents with internal applications, external APIs, databases, and enterprise systems. Implement multi-agent workflows, human-in-the-loop approvals, and appropriate security guardrails
  - Test, evaluate, and optimize agent accuracy, reliability, and performance
- Microsoft Azure & Enterprise Integrations
  
  - Build and deploy AI agents that operate within Microsoft Teams and other Microsoft 365 applications
  - Integrate AI agents with Microsoft Graph API to access authorized resources such as SharePoint, Outlook, OneDrive, Teams, and calendars
  - Implement secure authentication and authorization using Microsoft Entra ID (Azure AD), OAuth 2.0, and single sign-on (SSO)
  - Work with delegated permissions, application permissions, app registrations, and On-Behalf-Of (OBO) authentication flows
  - Develop backend APIs and services to support agent interactions with enterprise applications. Ensure secure data access and appropriate user-level permissions across integrations
- Open-Source LLMs & Model Fine-Tuning
  
  - Work with commercial and open-source/open-weight LLMs, including models such as Llama, Qwen, and Mistral
  - Fine-tune and customize LLMs for domain-specific applications, enterprise workflows, and specialized tasks
  - Apply parameter-efficient fine-tuning techniques such as LoRA and QLoRA
  - Prepare training datasets, perform data preprocessing, and develop model evaluation pipelines
  - Experiment with inference optimization, quantization, and model serving frameworks
  - Evaluate and compare open-source and commercial LLMs based on accuracy, latency, scalability, and cost
  - Work with frameworks and libraries such as Hugging Face Transformers, PEFT, PyTorch, and related tools
  - Support the deployment and integration of fine-tuned models into AI applications and agent workflows
- Azure Infrastructure & DevOps
  
  - Provision, configure, and manage cloud infrastructure for AI applications within Microsoft Azure. Work with Azure services including:
    
    - Microsoft Foundry / Azure AI Foundry
    - Azure OpenAI Service
    - Azure App Service, Azure Functions, and Azure Container Apps
    - Azure AI Search
    - Azure Storage and database services
    - Azure Key Vault
    - Azure Monitor and Application Insights
    - Microsoft Entra ID
  - Build and maintain CI/CD pipelines using Azure DevOps
  - Manage source control, deployments, and environment configurations using Git and Azure DevOps
  - Support infrastructure as code using Terraform or Bicep
  - Implement monitoring, logging, error handling, and troubleshooting for production AI systems
  - Optimize cloud infrastructure for performance, reliability, security, and cost
