## **About the Role :**

We are looking for a hands-on **Full-Stack Software Engineer** with strong backend expertise in Python and experience building modern, scalable web applications.

This role involves working across the complete technology stack, including backend services, APIs, databases, cloud infrastructure, and user-facing applications. The ideal candidate should be comfortable owning features end-to-end—from technical design and development through deployment and production support.

You will work closely with product, design, engineering, and AI teams to build and deliver high-quality, scalable software solutions.

## **Key Responsibilities :**

### Full-Stack Development

- Design, develop, and deliver full-stack features from technical specifications through deployment.
- Build and maintain backend services using **Python** and modern frameworks such as **FastAPI**.
- Develop and maintain transactional backend services using **TypeScript and Node.js frameworks**, preferably NestJS.
- Build responsive and scalable user interfaces using **React and Next.js**.
- Work across APIs, database schema changes, backend services, frontend applications, and production rollouts.

### Backend & API Development

- Design and maintain scalable Python services for processing workflows and application functionality.
- Build and maintain RESTful APIs with strong request validation and error handling.
- Develop asynchronous and message-driven workflows using technologies such as **Google Cloud Pub/Sub, Kafka, SQS, or similar platforms**.
- Ensure systems are designed with appropriate handling for retries, idempotency, and failed message processing.
- Write clean, reliable, fault-tolerant, and well-tested Python, TypeScript, and SQL code.

### Database & Application Architecture

- Design and manage relational database schemas, preferably using **PostgreSQL**.
- Work with database migrations, indexing, query optimization, and performance tuning.
- Use modern ORM technologies such as **SQLAlchemy, TypeORM, Prisma, Drizzle, or similar tools**.
- Contribute to scalable application architecture and maintain clear boundaries between services and application components.
- Support authentication, authorization, and secure access control using **OAuth/OIDC, JWT, RBAC, ACLs, Firebase Auth, or equivalent technologies**.

### Frontend Development

- Build and maintain modern web applications using **React and Next.js**.
- Develop accessible, responsive, and user-friendly interfaces.
- Work with modern frontend development and validation tools to deliver reliable user experiences.

### Cloud & DevOps

- Deploy and manage applications on cloud infrastructure, preferably **Google Cloud Platform (GCP)**.
- Work with cloud services such as **Cloud Run, Cloud SQL, Cloud Storage, and Pub/Sub**.
- Use Docker and CI/CD pipelines to support reliable application deployment and delivery.
- Implement logging, monitoring, metrics, and alerts to support production systems.

### AI & Modern Development Practices

- Work with AI-powered applications and gain exposure to **LLM and agent frameworks**.
- Support the integration of AI services, tools, and long-running processing workflows into production applications.
- Use AI-assisted development and coding tools to improve productivity, code quality, testing, and development workflows.
- Follow engineering best practices including code reviews, testing, documentation, and knowledge sharing.

### Collaboration

- Work closely with Product Managers, Designers, Engineers, and other stakeholders to translate business requirements into scalable technical solutions.
- Communicate technical decisions, trade-offs, and risks clearly to both technical and non-technical stakeholders.
- Take ownership of features and contribute throughout the complete software development lifecycle.
