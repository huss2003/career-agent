Job Description

**Job Summary:**

As a Software Engineer – Product Security, you will join a team that helps ensure Rockwell Automation products are designed, developed, and maintained using industry-leading secure development practices.

You will work closely with software development teams, architects, product security engineers, and DevSecOps teams to implement security capabilities, address vulnerabilities, automate security workflows, and improve the overall security posture of our products.

You will provide opportunities to contribute across the software development lifecycle, from design and implementation through testing, deployment, and maintenance.

You are a collaborative engineer who enjoys solving technical problems, learning new technologies, and working with globally distributed teams.

In addition to software engineering fundamentals, you have an interest in cybersecurity, secure software development, cloud technologies, and new AI-assisted development practices.

You will report to the SENIOR MANAGER, SOFTWARE ENGINEERING and have a hybrid schedule working in **Bangalore or Pune, India.**

### Your Responsibilities:

- Develop software components, services, and tools supporting product security programmes.
- Apply secure coding practices and security-by-design principles throughout the software development lifecycle.
- Participate in feature design, implementation, testing, and deployment activities.
- Support threat modelling, security reviews, vulnerability remediation, and risk mitigation efforts.
- Develop automation solutions that improve security, compliance, and engineering productivity.
- Contribute to cloud-native, web, desktop, or distributed application development.
- Collaborate with software engineering teams to integrate security requirements into product designs and implementations.
- Investigate, troubleshoot, and resolve software defects, performance issues, and security findings.
- Participate in code reviews, design reviews, and technical discussions.
- Create technical documentation, test plans, and engineering artefacts.
- Support DevSecOps projects by integrating security tooling into CI/CD pipelines.
- Use Generative AI tools responsibly to improve software development efficiency, code quality, testing, documentation, and engineering workflows.
- Learn and stay current with latest technologies, cybersecurity threats, software engineering practices, and AIdriven development methodologies.
- Collaborate with global teams.

### The Essentials - You Will Have:

- Bachelor's Degree in Computer Science, Information Technology, Computer Engineering, Software Engineering, Cybersecurity, Electronic & Communication Engineering, or equivalent practical experience
- Product Security & DevSecOps Knowledge of secure software development lifecycle (SSDLC) practices.
- Understanding of common software vulnerabilities and mitigations (OWASP Top 10, CWE, secure coding practices).
- Familiarity with threat modelling concepts and security risk assessments
- Experience developing software using one or more modern programming languages such as C#, C++, Java, Python, Go, or TypeScript.
- Experience working in Agile development environments.

- Experience developing software for cloud, web, desktop, or distributed systems.
- Experience with object-oriented design principles, data structures, algorithms, and design patterns.

- Experience developing software on Windows and Linux platforms.
