## We are looking for a **Software Engineer** to design, build and operate modern enterprise applications and digital platforms.

## You will work across frontend, backend and integration layers, building reliable software that connects with enterprise systems, provides intuitive user experiences, and is observable and supportable in production.

## This is a hands-on engineering role with an expectation of **end-to-end ownership**, from understanding requirements and designing solutions through development, testing, deployment and production support.

## Key Responsibilities

- ## Design, develop and maintain scalable **web applications and services**.
- ## Build modern frontend experiences using **React / JavaScript / TypeScript**.
- ## Develop backend services and **REST APIs using Java and Spring Boot**.
- ## Design and integrate solutions with enterprise systems through **REST APIs, Microsoft Graph and other integration interfaces**.
- ## Work with **PostgreSQL and relational databases**, including data modelling and query optimisation.
- ## Build software that consumes information from multiple systems and presents it through simple, user-friendly experiences.
- ## Implement authentication and authorisation using modern standards such as **OAuth 2.0 / OpenID Connect and Microsoft Entra ID**.
- ## Build applications with appropriate **logging, metrics, monitoring and observability**.
- ## Develop dashboards and monitoring capabilities using technologies such as **Prometheus, Grafana and Loki**.
- ## Write clean, maintainable and well-tested code following established engineering standards.
- ## Build automated **unit, integration and API tests**.
- ## Participate in code reviews and contribute to improving engineering practices.
- ## Work with CI/CD pipelines to automate build, testing and deployment.
- ## Troubleshoot application, API, integration and production issues.
- ## Apply **secure-by-design** principles throughout development.
- ## Collaborate with product owners, UX designers, architects, support teams and other engineers to translate business requirements into working software.
- ## Take ownership of features from **design → development → deployment → monitoring → continuous improvement**.
- ## Maintain technical documentation for APIs, integrations and application components.

## Engineering Expectations

## At **JL3**, we would expect the engineer to:

- ## Independently deliver well-defined features and technical components.
- ## Understand an existing system and make changes without creating unnecessary complexity.
- ## Break requirements into practical engineering tasks.
- ## Identify technical issues early and raise risks appropriately.
- ## Debug across frontend, backend, database and API/integration layers.
- ## Write production-quality code rather than prototype-only solutions.
- ## Consider **performance, reliability, security and maintainability** during implementation.
- ## Own defects in their area and drive them through resolution.
- ## Communicate technical decisions clearly with other engineers and stakeholders.
- ## Actively contribute to code reviews, documentation and team engineering standards.

## Software Engineering Mindset

## We are particularly looking for engineers who:

- ## Think beyond simply implementing a ticket.
- ## Ask **why** a feature is required before deciding **how** to build it.
- ## Prefer reusable APIs and components over one-off solutions.
- ## Automate repetitive engineering and operational tasks.
- ## Treat **monitoring and observability as part of the product**, not something added after deployment.
- ## Design for failure and consider what happens when an external dependency or API is unavailable.
- ## Build simple experiences on top of potentially complex enterprise systems.
- ## Take responsibility for software after it reaches production.
- ## Continuously improve existing solutions rather than only developing new features.
