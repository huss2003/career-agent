Come build the infrastructure that AI runs on.

## The Team

You'll work on three things together: Atlan's context layer, the platforms that make it usable, and the agents that run on top of it.

The platform handles the things agents need to be trusted in production: knowing which agents and skills exist, understanding what happened during a run, evaluating how well they performed, and controlling access and cost.

Then there are the agents themselves. Each one is built to do a specific job, either for our customers or for our own teams. These aren't demos sitting on a slide. We already have an agent our CSMs rely on, three GTM agents that replace around 3,000 manual calls, an agent that watches changes across , and an agent that monitors our other agents.

We share what we're learning through Becoming Frontier.

**You'll own the frontend, but you won't be limited to the frontend.** We use AI heavily in how we build, and we expect you to be comfortable working across the stack.

We work in small "two-slice" teams. You'll typically own an initiative with one or two other people. There's no large team around you to hand work off to, so you'll have a lot of ownership over how something gets built.

## What will you do?

- **Take a 0→1 idea all the way to production.** Figure out the problem, write the spec when one doesn't exist, make the architecture decisions and build it.
- **Own the frontend experience for agents.** Build the interfaces people use to find, run, inspect and approve agents. Care about rendering performance and build components that other engineers can build on.
- **Work beyond the frontend.** Use coding agents to navigate unfamiliar backend code, make changes and validate their output rather than blindly trusting what they generate.
- **Build agents with the people who will actually use them.** Demo early, learn from real usage and put the agent into the workflow where the work already happens.
- **Design for things going wrong.** Think through what happens when a tool fails, context is missing, an agent isn't confident or a human needs to take over.
- **Make agent behavior observable.** Connect traces and evals to the version of the agent that produced them, and treat changes in quality as regressions worth investigating.
- **Build AI-native yourself.** Use coding agents as part of your daily workflow, while keeping the engineering and architectural bar high.
- **Share what you learn.** Turn useful patterns into skills, reference architectures and demos that other engineers can build on.

## What makes you a great match for us?

### Must have

- **Strong frontend fundamentals.** You've shipped production UIs using React, Vue or something similar with TypeScript, and you've dealt with hard problems around rendering performance, component systems or framework migrations.
- You've taken 0→1 products from an idea to production, often without a neatly defined spec.
- You've shipped agents or LLM-powered systems that real people use, and can debug failures down to the context, tool call or decision that caused them.
- You use evals to understand where agents fail and improve them based on real user impact.
- You use coding agents regularly and hold their output to the same engineering bar as your own.
- You're a critical optimist. You can get excited about new technology without taking it at face value, and you're comfortable reasoning from first principles.
- You enjoy owning an initiative with a small number of people rather than working as one part of a large team.

### Strong bonus

- **React, Vite and TypeScript**, which is our current stack.
- Experience with MCP, A2A, agent frameworks, LLM gateways or agent observability.
- Experience as a founding engineer or working at an early-stage startup.
- A public trail of work, such as an active GitHub, npm packages or open-source contributions, that gives us a sense of how you build.

### This probably isn't for you if...

You want to manage a large team, prefer having a well-defined backlog handed to you, **only want to work on the frontend**, or are still waiting to start working with AI.

We're looking for someone who wants to build with this technology now.
