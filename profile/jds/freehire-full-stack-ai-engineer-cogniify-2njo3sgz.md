**The Role**

Cogniify is hiring Full Stack AI Engineers to build web-based applications with AI capabilities from the ground up. You will work with engineers and product teams to develop the application interface, backend services, databases and AI features that help users complete real tasks.

We are looking for developers with strong full stack fundamentals and practical AI integration experience. You may specialize in Java or Python on the backend. Depending on your strengths, you may focus more on application development or AI features, while working closely with the rest of the team.

This is a remote role open to candidates across India. Some overlap with US Pacific time is required for team meetings and handovers.

**What You Will Do**

- Build and improve web applications, including user-facing screens, backend services and databases.
- Develop backend services and REST APIs using either Java with Spring Boot and microservices, or Python with Django, Django REST Framework or FastAPI.
- Build frontend features using React or Next.js with JavaScript or TypeScript, and connect them to backend APIs.
- Design database tables and write reliable SQL queries using PostgreSQL, MySQL or a similar database.
- Connect applications to large language models (LLMs) through APIs to add useful AI features.
- Build and integrate MCP (Model Context Protocol) servers so AI applications can securely access approved tools and data.
- Work on AI agents that can call tools and carry out multi-step tasks, and build RAG features that retrieve relevant information to support AI responses.
- Write clean, testable code, investigate bugs and participate in code reviews.
- Work with the deployment team to release applications and resolve issues after launch.
- Use AI coding assistants, such as Claude Code or similar tools, where helpful, while reviewing and testing the code they produce.

**What We Are Looking For**

- 3 to 6 years of hands-on experience developing web applications.
- Strong backend development experience in at least one stack: Java, Spring Boot and microservices, OR Python, Django and related API frameworks.
- Hands-on frontend development experience with React or Next.js, and JavaScript or TypeScript.
- Good knowledge of SQL, relational databases and basic database design.
- Practical experience integrating LLM APIs into applications, such as Claude, OpenAI or similar models.
- Hands-on experience building or integrating MCP servers and connecting AI applications to tools or data.
- Understanding of AI agents and RAG, with exposure to building or integrating these features.
- Experience developing REST APIs, using Git and writing unit or integration tests.
- Good communication skills and comfort working with colleagues in different time zones.

**Good to Have**

- Experience with agent frameworks such as LangChain, LangGraph, Spring AI or LangChain4j.
- Experience with vector search or vector databases such as pgvector, Pinecone or similar tools.
- Experience with model training or fine-tuning. This is not required for the role.
- Familiarity with LLMOps, monitoring AI features, evaluating AI responses or prompt testing.
- Exposure to Docker, CI/CD and deployment on AWS, Azure or Google Cloud. A separate deployment team is available.
- Experience working with distributed or fully remote engineering teams.
