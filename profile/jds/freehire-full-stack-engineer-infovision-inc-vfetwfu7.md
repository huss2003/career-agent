**Job Description – Full Stack Developer (React.js | TypeScript | Node.js)**

**Role Overview**

We are looking for an experienced Full Stack Developer with strong expertise in React.js and TypeScript to build scalable, high-performance web applications, APIs, and interactive dashboards. The role involves developing modern frontend architectures, backend services, and integrating enterprise data platforms and AI-powered features.

**Key Responsibilities**

- Design, develop, and maintain scalable React.js applications, dashboards, and data-driven web platforms.
- Build responsive, high-performance UIs using React.js, TypeScript, Next.js, and modern CSS frameworks.
- Develop interactive dashboards and data visualisations using D3.js, Recharts, or Chart.js.
- Implement state management using Redux Toolkit, Zustand, or React Query.
- Design and develop RESTful APIs using Node.js (Express/Fastify) or Python (FastAPI).
- Build secure backend services with authentication, authorisation, API versioning, and database integration.
- Work with PostgreSQL, MongoDB, and Redis for data storage, querying, and caching.
- Integrate applications with enterprise data platforms, third-party APIs, and cloud services.
- Implement AI-powered features using LLM APIs, OpenAI, Azure OpenAI, and RAG.
- Manage CI/CD pipelines, Docker containerisation, and cloud deployments.
- Ensure application security, performance optimisation, automated testing, and code quality.

**Must-Have Skills**

- 5–7 years of professional Full Stack Development experience.
- 4+ years of strong hands-on experience with React.js.
- Proficiency in JavaScript (ES6+), TypeScript, HTML5, and CSS3.
- Strong experience with React Hooks, component architecture, and frontend performance optimisation.
- Hands-on experience developing and consuming REST APIs using Node.js (Express/Fastify) or Python (FastAPI).
- Experience with PostgreSQL, MySQL, or MongoDB.
- Knowledge of Redux Toolkit, Zustand, React Query, or similar state management tools.
- Experience with Azure or AWS cloud services.
- Strong understanding of web security, authentication, and authorisation.
- Experience with Git, Docker, CI/CD pipelines, and Agile development practices.

**Good-to-Have Skills**

- Experience with Next.js, GraphQL, and WebSockets.
- Knowledge of D3.js, Recharts, Plotly, or other data visualisation libraries.
- Experience integrating OpenAI, Azure OpenAI, or Anthropic APIs and implementing RAG.
- Familiarity with Databricks, Apache Spark, and data warehouse concepts.
- Exposure to Kubernetes, Terraform, Redis, and event-driven architecture.
- Experience with Jest, Cypress, Playwright, and Storybook.
- Understanding of accessibility standards (WCAG) and responsive design.

**Education**

Bachelor’s or Master’s degree in Computer Science, IT, or a related discipline.

**Key Competencies**

- Strong problem-solving and analytical skills.
- Ownership of end-to-end application development.
- Ability to translate business requirements into technical solutions.
- Strong communication, collaboration, and mentoring skills.
