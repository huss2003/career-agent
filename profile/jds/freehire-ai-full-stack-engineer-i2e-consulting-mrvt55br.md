This role requires a developer who views AI as a core engineering capability rather than simply a coding assistant. The candidate should be capable of utilising AI throughout the software development lifecycle, including requirement analysis, solution design, architecture generation, code development, testing, documentation, code reviews, debugging, optimisation, and deployment automation. The candidate must be able to independently reason about and validate AI-generated output, rather than accepting AI-suggested code at face value, verifying whether the underlying logic is correct, efficient, and the most appropriate of the several possible ways to solve a problem. This role is looking for candidates who bring that discipline.
