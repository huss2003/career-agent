**Job Summary** :

We are looking for an experienced Azure .NET Developer with extensive expertise in the Microsoft Azure ecosystem to contribute to the technical delivery of an enterprise-grade application within an Agile framework. This position encompasses comprehensive responsibilities including the identification and development of reusable components, implementation of software design patterns, oversight of development processes, and management of integration requirements. The successful candidate will collaborate effectively with both internal and external integration teams to deliver scalable and secure solutions.

**Key Responsibilities:**

**1. Technical Leadership :**

- Prioritize AI throughout the SDLC.
- Skilled in AI-assisted coding tools for higher productivity.
- Skilled in one stack and adaptable polyglot engineer across entire application stack.
- Design and develop solutions with Azure, ReactJS and .NET.
- Set standards in code, reviews, and best practices.
- Guarantee architecture compliance, performance, and technical quality.

**2. Agile Delivery:**

- Work with the Product Owner and Scrum Master to plan sprints, estimate tasks, and refine the backlog.
- Break down business requirements into technical stories or tasks.
- Participate in daily stand-ups and technical ceremonies as required.

**3. Integration Ownership:**

- Contribute to all aspects of application integration, including REST APIs, Azure Service Bus, Event Grid, Logic Apps, and other Azure Integration Services.
- Serve as the primary point of contact for integration requirements, coordinating with platform and partner teams as necessary.
- Prepare and verify API contracts, data models, event schemas, and integration patterns through comprehensive documentation and validation processes.

**4. Requirement & Interface Management:**

- Convert application-specific features into precise technical artifacts.
- Coordinate system interface specifications, data flow processes, and communication protocols.

**5. Stakeholder Communication:**

- Share technical vision, risks, and progress with architects, project managers, and business stakeholders.
- Participate in cross-team architecture and design discussions as an application representative.

**6. DevOps & Quality Assurance:**

- Advocate for CI/CD best practices.
- Oversee implementation of monitoring, logging, and alerting through Azure Monitor, Application Insights, and Log Analytics.
- Ensure thorough automated testing, adherence to secure development protocols, and readiness for release.

**Required Skills:**

- Experienced with Azure PaaS (App Services, Functions, API Management, Service Bus, Event Grid, Logic Apps).
- Skilled in .NET Core, C#, Web APIs, ReactJS, and SQL Server RDBMS.
- Proficient in using AI code generation tools like GitHub Copilot, Codex, Claude Code, Cursor, etc.
- Understanding of CI/CD and infrastructure automation.
- Knowledgeable about integration patterns (sync/async, event-driven, pub-sub).
- Familiar with Agile and DevOps practices.
- Strong communication and stakeholder management abilities.

**Preferred Qualifications:**

- Microsoft Certified: Azure Solutions Architect or Azure Developer Associate.
- Demonstrated proficiency in secure design methodologies, including OAuth2, Azure Active Directory, Managed Identity, and Azure Machine Learning.
- Insurance Domain knowledge or products used in that space.
