**Job Description - Database Administrator**

We are seeking an experienced and highly motivated professional to manage and optimize enterprise database environments, cloud infrastructure, and automation solutions. **Key Responsibilities**

**Database Administration :**

Manage, monitor, and maintain Oracle, PostgreSQL, or other enterprise databases.

Perform database installation, configuration, upgrades, patching, and migrations.

Implement backup, recovery, high availability (HA), and disaster recovery (DR) solutions.

Monitor database health, capacity planning, and storage utilization.

Database Archiving, purging and data masking.

Ensure database security, user management, and compliance standards.

**Performance Tuning**

Perform server installation, configuration, troubleshooting, and patch management.

Manage file systems, process monitoring, networking, security hardening, and user administration.

Develop shell scripts for automation and operational efficiency.

Python Programming & Automation
