The Connect UI team builds the experiences Confluent Cloud customers use to bring data into and out of Kafka. That covers browsing and setting up fully managed and custom connectors, troubleshooting connector failures with AI assistance, and visualizing how connectors are performing. Connectors are where customers' real-time data enters the platform, so the quality of what we build directly affects how quickly customers get up and running About the Role We are looking for a Frontend Software Engineer who's excited to help build engaging, intuitive products for managing and visualizing large-scale, real-time data streams. Data flow is central to how companies operate, and we aim to make that experience simple and attractive. Working with mentorship from senior engineers, you will help develop features across the Connect experience in Confluent Cloud and steadily grow into an owner of parts of the product. Our Cloud UI is built with React and TypeScript on our own design system, and connects to multiple REST and GraphQL APIs. We test with Jest and React Testing Library (unit) and Playwright (end-to-end). We deploy to production daily and can test every commit, including PRs, before it goes live. Feature flags let us release independently of backend teams, and bots keep our dependencies up to date. AI-assisted development tools are part of our everyday engineering workflow. As a Frontend Software Engineer, you will help build client-side features for data-intensive products, working closely with senior engineers, designers and product managers. You will: Help develop new features from user requirements and designs, taking on well-defined tasks within larger features, delivering them on time, refining them based on feedback, and growing the scope you own over time. Build UI components and interactions to the design specifications using our design system, and integrate with backend APIs, working with backend engineers to understand API contracts and handle loading, error and empty states well. Write clean, readable code with unit and end-to-end tests, and write short design notes for your tasks for peer review. Take part in code reviews, both receiving and giving feedback. Help investigate and fix bugs and production issues, starting by shadowing the on-call rotation. Share your progress clearly in standups and project updates, and raise blockers early. Learn Confluent's engineering practices, including release, monitoring and feature flag processes, and how our product works end to end.
