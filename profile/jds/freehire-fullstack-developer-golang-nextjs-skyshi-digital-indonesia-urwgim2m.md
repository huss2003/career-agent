The Fullstack Engineer designs, builds, and maintains end-to-end features for client Skyshi enterprise eprocurement platform — part of the eSuite business-application ecosystem — covering the procure- to- pay lifecycle: purchase requisitions, purchase orders, goods receipt, sourcing events, contracts, supplier management, and the configuration layer that lets each company tailor procurement to its own processes. The role delivers reliable, maintainable software across Go backend microservices and a React / Next.js micro-frontend, working inside a live, multi-company production platform. This position joins the eprocurement squad for the next phase of the product. Engineers work as peers, each taking full ownership of features from requirement to production deployment, while collaborating closely with product, QA, and fellow engineers.

**Key Responsibilities**

**1. Backend Development & APIs**

- Design, develop, and maintain Go backend microservices exposing REST and gRPC / Protobuf APIs, following clean / layered architecture.
