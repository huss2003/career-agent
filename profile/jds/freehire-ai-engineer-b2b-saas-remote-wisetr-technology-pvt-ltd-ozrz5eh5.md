FunnelKit builds powerful no-code funnel and marketing automation products for businesses worldwide. Our mission is to help small businesses grow profitably by giving them the right tools to increase conversions and revenue, without unnecessary complexity.

We are a product-first, customer-driven team that values ownership, simplicity, kindness, and excellence.

**Role Overview**

This role is ideal for someone who:

- Treats AI as an engineering discipline: you design for results a store owner can rely on, and you test that reliability instead of stopping once the model responds.
- Has spent 3+ years putting AI/ML and LLM features in front of paying customers in a live product.
- Picks up an ambiguous problem, decides how to attack it, and delivers without close direction.
- Writes and speaks clear English, and can walk engineers, designers, product managers and support colleagues through a technical trade-off.

At FunnelKit and Sublium, AI sits inside the tools merchants use every day: suggesting funnel and checkout improvements, drafting email and on-site copy, grouping customers into segments, and automating routine marketing work. You will build these capabilities, along with the internal AI tooling our own teams use for reporting and decision support.

You will carry a project from first data exploration through model choice, evaluation, API and interface work, release and production monitoring, working daily with Product, Engineering, Design, QA and Customer Success.

**Key Responsibilities**

**Build AI Features for Merchants**

- Ship AI capabilities inside FunnelKit and Sublium, such as funnel and checkout recommendations, email and SMS copy drafting, customer segmentation, revenue forecasting and agent-style automations.
- Take a merchant’s goal and store data and produce suggestions concrete enough to act on. After launch, study real usage and plan the next iteration.
- Agree success metrics and event tracking with the Product Manager before you build.

**Design the LLM Layer**

- Create prompt templates, schema-validated responses, tool calls, retrieval (RAG) and safety checks, and chain them into multi-step agent flows where they add value.
- Compare models, frameworks and hosting options for each use case against quality, response time and spend.
- Add fallback providers, response caching and spend limits so features stay dependable at scale.

**Work with Data**

- Prepare imperfect store, funnel and event data for analysis and for use as model input.
- Anchor generated text to real figures from the merchant’s account, so AI output never contains invented numbers.
- Run the pipelines that collect, transform and serve this data to AI features and internal reports.

**Measure and Protect Quality**

- Build evaluation sets and monitoring so you can show that each release beats the previous one and catch regressions before merchants do.
- Report quality, latency and per-request cost on dashboards shared with the team.
- Help QA design tests for output that changes from run to run.

**Own Delivery End to End**

- Implement the backend services (Python or TypeScript) and the TypeScript and React interface that carry a result to the merchant, and deploy them.

**Build Internal AI Tools**

- Create AI-assisted reporting, analytics and workflow tools for Support, Marketing and Product teams, simple enough that non-engineers use them without help.

**Engineering Habits and Sharing**

- Deliver tested, maintainable code with error handling, logging and tracing.
- Use AI coding assistants daily, and check their output before it is merged.
- Write down how each solution works and how AI helped build it, so colleagues can reuse the approach.
- Follow developments in models and tooling, and propose what is worth adopting.

**Collaboration and Customer Support**

- Work with Product, Design, QA and Customer Success to turn customer problems into improvements.
- Set privacy, safety and compliance rules for AI features, with legal and security input where needed.
- Make features explainable to L1/L2 support teams, and help diagnose serious production problems.
