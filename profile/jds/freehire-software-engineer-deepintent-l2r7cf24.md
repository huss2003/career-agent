**What You’ll Do:**

- Build full stack features using React, Java/Spring Boot, and REST APIs.
- Develop responsive, accessible UI components with TypeScript.
- Implement backend APIs and integrate GraphQL based UI data access.
- Write SQL queries and support data ingestion, transformation, and reporting.
- Contribute to batch and event driven data processing under engineering guidance.
- Write well tested code, review peers’ work, and troubleshoot performance issues.
- Use AI coding tools for design, development, testing, and documentation.
- Review, test, and debug AI generated code while protecting sensitive data.
- Collaborate with Product, UX, QA, and engineers to ship integrated features.
- Work in Agile teams and contribute to production support.

**Who You Are:**

- Bachelor’s degree in Computer Science/Engineering or equivalent experience.
- 1.5+ years of development experience with contributions to both frontend and backend.
- Hands on with React, JavaScript (ES6+), and TypeScript.
- Working knowledge of Java, Spring Boot, and REST API development.
- Comfortable writing SQL and using relational databases (MySQL or PostgreSQL).
- Familiar with state management and data fetching (Zustand, GraphQL/React Apollo).
- Understands data structures, API design basics, and clean, testable code.
- Familiar with unit testing, Git, debugging, and Agile development practices.
- Uses AI coding tools (Cursor, Claude Code, Copilot, or similar) in real projects.
- Can validate AI generated code and follow AI security and data privacy guardrails.
- Exposure to CI/CD, cloud (AWS/GCP), Kafka, data pipelines, or NoSQL is a plus.
- Takes ownership, communicates clearly, and is eager to learn across the stack.
