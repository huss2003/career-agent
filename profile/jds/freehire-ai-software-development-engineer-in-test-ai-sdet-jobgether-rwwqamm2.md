**This position is listed on behalf of a partner company, who manages all applications and next steps. Our partner is looking for an AI – Software Development Engineer in Test (AI – SDET) based in India.**

As an AI Software Development Engineer in Test, you will play a key role in redefining quality engineering for next-generation AI-powered applications and autonomous systems. You will go beyond traditional software testing to evaluate, validate, and improve large language models (LLMs), AI agents, copilots, chatbots, and intelligent workflows. You will design scalable automation frameworks and AI evaluation systems to ensure the reliability, safety, accuracy, and performance of AI-driven solutions. Working closely with Engineering, AI/ML, Product, Platform, and DevOps teams, you will contribute to the development of robust, cloud-native applications. You will also help advance AI testing methodologies through experimentation, automation, and emerging technologies. This is an exciting opportunity to shape modern quality engineering practices in an innovative, collaborative, and globally distributed environment.

### Accountabilities:

- AI and LLM Quality Engineering
- Design, implement, and optimise testing strategies for AI-powered applications, copilots, chatbots, Retrieval-Augmented Generation (RAG) pipelines, and autonomous AI agents.
- Develop AI evaluation (Evals) frameworks to assess hallucinations, groundedness, toxicity, bias, response quality, contextual relevance, prompt regression, consistency, and safety.
- Build automated validation pipelines for LLM outputs using structured assertions, semantic scoring, embeddings, and evaluation metrics.
- Create synthetic and benchmark datasets to support comprehensive AI testing scenarios.
- Test multi-agent orchestration workflows, including agent memory, context retention, planning, and execution.
- Validate Model Context Protocol (MCP) integrations and interoperability between AI models and external tools.
- Apply Context Engineering, Prompt Engineering, and prompt optimisation techniques to improve AI reliability and output quality.
- Evaluate AI system performance, including latency, token consumption, cost efficiency, throughput, and scalability.
- Automation Engineering
- Develop, maintain, and scale UI and API automation frameworks using Python, preferably with Robot Framework and tools such as Playwright, Selenium, or Cypress.
- Automate testing across REST APIs, GraphQL APIs, event-driven systems, streaming applications, webhooks, microservices, and Micro Frontend (MFE) architectures.
- Build reusable automation libraries, testing utilities, and AI-assisted quality engineering workflows.
- Integrate automated testing into CI/CD pipelines and implement quality gates to improve software delivery reliability.
- AI Engineering and Platform Validation
- Validate RAG architectures by assessing document chunking strategies, embedding quality, retrieval accuracy, re-ranking, and vector search relevance.
- Work with vector databases and search technologies, including Pinecone, Weaviate, ChromaDB, Qdrant, and FAISS.
- Build, test, and validate AI agents using frameworks such as LangChain, LangGraph, CrewAI, AutoGen, Semantic Kernel, and OpenAI SDKs.
- Test advanced AI capabilities, including tool calling, function calling, agent memory, planning and execution, multimodal workflows, and structured outputs.
- DevOps, Observability, and Reliability
- Build and maintain automated quality workflows integrated with CI/CD platforms such as GitHub Actions, Jenkins, GitLab CI/CD, and Azure DevOps.
- Work with Docker and Kubernetes environments to validate application deployment, scalability, and reliability.
- Perform cloud-based testing and deployments across AWS, Azure, Oracle Cloud Infrastructure (OCI), and Google Cloud Platform (GCP).
- Validate distributed systems, focusing on reliability, resilience, and performance under different operating conditions.
- Monitor AI system behaviour using observability, logging, and distributed tracing tools.
- Promote shift-left testing practices and contribute to continuous improvement in quality engineering standards.
