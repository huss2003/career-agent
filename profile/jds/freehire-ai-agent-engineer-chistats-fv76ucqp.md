**About ChiStats:**

ChiStats is an award-winning Data Science and AI Engineering company building intelligent technology solutions for the Financial Services and BFSI ecosystem. From AI-powered compliance platforms to scalable data products, we help financial institutions simplify complexity, automate operations, and stay ahead in a rapidly evolving regulatory landscape.

Our flagship platform, ComplianceAssist, enables Mutual Funds, AMCs, PMS, and AIFs to transform regulatory compliance into a streamlined, automated, and insight-driven process. As we continue to expand, we are building the next generation of AI-led products and solutions for the WealthTech industry. We are looking for engineers to build applications and personal-agent experiences on top of frontier AI lab platforms, including personal agent products such as Muse, Dot and similar.

You will design agentic workflows, build AI agents that use tools and APIs to get real work done, and integrate apps through platform SDKs so agents can act on users' behalf across services.

**Key responsibilities:**

\- Design, build and ship AI agents and personal-agent use cases on frontier lab platforms (e.g., Muse, Dot and comparable ecosystems).

\- Build multi-step agentic workflows: planning, tool selection, task decomposition, memory, and human-in-the-loop checkpoints.

\- Integrate third-party apps and services through Apps SDKs, tool/function-calling interfaces and REST/GraphQL APIs.

\- Build and maintain tool connectors (including MCP servers or similar tool protocols) that expose data and actions to agents securely.

\- Implement context and memory management, including retrieval (RAG), session state and user personalization.

\- Engineer and iterate on prompts, system instructions and tool schemas to improve reliability, accuracy and cost.

\- Set up evaluation, testing and observability for agent behaviour (success rates, failure analysis, latency and token cost).

\- Handle authentication and permissions for connected apps (OAuth 2.0, API keys, scoped access) with attention to user privacy and safety.

\- Collaborate with product and design to turn user needs into agent capabilities, and prototype quickly to validate ideas.

\- Keep up with fast-moving frontier lab releases, SDKs and agent frameworks, and bring relevant improvements into the product.
