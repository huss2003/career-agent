About the role
We are looking for a software developer to design, build and maintain applications for IP cameras, video surveillance and connected security systems.
The role involves integrating cameras and recording systems, processing live and recorded video, developing web applications, and connecting security platforms with third-party systems. Projects may include remote monitoring, video management, scheduled image capture, time-lapse, event automation and analytics integration.

Key responsibilities

Integrate IP cameras, NVRs and video management systems using ONVIF, RTSP, HTTP APIs and manufacturer SDKs.
Develop applications for live viewing, recording, playback, image capture and media export.
Build web dashboards for device configuration, monitoring, reporting and user management.
Implement event-driven workflows, alarms, notifications and integrations with external systems.
Develop video-processing features such as clipping, overlays, format conversion and time-lapse generation.
Build reliable background services with connection recovery, error handling and system-health monitoring.
Design databases and storage workflows for device information, recordings, images and events.
Implement secure authentication, role-based permissions, credential storage and audit logs.
Deploy and maintain applications on local servers, edge devices or cloud infrastructure.
Test with real devices, troubleshoot compatibility issues, and maintain technical documentation.
Work with project and technical teams to translate customer requirements into practical software solutions.

Required skills and experience

Strong programming skills in Python or C#/.NET, with experience delivering production applications.
Hands-on experience integrating IP cameras, video streams or surveillance systems.
Working knowledge of ONVIF, RTSP, HTTP/REST APIs and manufacturer SDKs. Practical experience with FFmpeg or GStreamer.
Understanding of video codecs, including H.264 and H.265, and their effects on bandwidth, storage and playback. Experience developing backend services, REST APIs and database-driven applications.
Familiarity with modern web development using JavaScript or TypeScript.
Understanding of IP networking, authentication and remote connectivity. Experience with Git, testing, logging and deployment.
Ability to investigate technical issues and independently deliver well-documented solutions.

Preferred skills

Experience with camera brands such as Hikvision, Dahua, Axis or Hanwha. Integration with VMS platforms, access control systems or other security applications.
React, Vue or a similar frontend framework.
WebRTC or HLS for browser-based video delivery.
OpenCV and integration of AI-based video analytics.
Docker, Linux, Windows services and cloud platforms.
Experience with multi-site systems, edge processing and storage optimization.
