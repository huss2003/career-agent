**Role Overview**

We are looking for a hands-on Full Stack AI Engineer to design, build, and deploy production-grade, AI-powered applications. - **Frontend Architecture:** Develop responsive, type-safe user interfaces and conversational dashboards using **React** and **TypeScript**.
- **Backend & API Development:** Design and implement robust backend services, microservices, and REST/GraphQL APIs in **Python**, ensuring thorough test automation (unit, integration, and end-to-end).
- **AI Orchestration & Agent Workflows:** Build multi-agent architectures, LLM orchestration layers, and evaluation pipelines using **LangChain**, **LangGraph**, and **MLflow**.

- **Experience:** 5-10years of relevant full-stack software development experience.

- **AI Stack:** Practical experience building LLM-driven applications using **LangChain** and multi-agent coordination using **LangGraph**; experiment tracking and model registry workflows with **MLflow**.
