We are hiring an **AI Engineer / AI Agent Developer** on behalf of our client. This role involves designing and building intelligent AI agents and LLM-powered applications that can reason, use tools, and automate real business workflows. It's a great opportunity for someone passionate about the future of AI who enjoys building autonomous systems and turning ideas into working products.

**Role & responsibilities**

- Design, build, and deploy **AI agents and multi-agent systems** that automate complex tasks
- Develop applications using **LLMs** (GPT, Claude, Llama, Gemini, etc.) and their APIs
- Build **RAG (Retrieval-Augmented Generation) pipelines** with vector databases and embeddings
- Implement **tool calling, function calling, and workflow orchestration** for agents
- Use agent frameworks such as **LangChain, LangGraph, LlamaIndex, CrewAI, or AutoGen**
- Apply **prompt engineering** techniques to improve agent accuracy, reliability, and safety
- Integrate agents with external APIs, databases, and business tools (CRM, Slack, email, etc.)
- Build **chatbots, copilots, and process automation solutions**
- Evaluate and monitor agent performance, latency, cost, and hallucination rates
- Implement **guardrails, memory, and context management** for production agents
- Deploy AI applications on cloud platforms using APIs and microservices
- Collaborate with product, engineering, and data teams to define AI use cases
- Stay updated on the latest AI research, agent frameworks, and tools

**Preferred candidate profile**

- Bachelor's/Master's degree in Computer Science, AI, Data Science, or related field
- 0 to 2 years of experience in AI/ML, software development, or related role (internships and projects count)
- Strong programming skills in **Python** (JavaScript/TypeScript is a plus)
- Hands-on experience with **LLM APIs** (OpenAI, Anthropic, Google Gemini, Hugging Face)
- Good understanding of **prompt engineering, RAG, and embeddings**
- Knowledge of **REST APIs, JSON, and backend development** (FastAPI, Flask)
- Basic understanding of **machine learning and NLP** concepts
- Strong problem-solving and analytical skills
- Good communication skills and eagerness to learn
