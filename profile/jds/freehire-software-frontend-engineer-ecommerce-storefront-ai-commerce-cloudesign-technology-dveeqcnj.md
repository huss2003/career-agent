## About the Role

We are looking for a Software Engineer with 2–4 years of experience to build modern ecommerce storefronts and AI-powered customer experiences. You will contribute to customer-facing applications built using modern frontend technologies while gaining exposure to next-generation AI-driven commerce solutions.

You will work across two key areas:

- **Ecommerce Storefront** – Building high-performance web applications using React, Astro, and modern frontend technologies.
- **AI Commerce** – Contributing to AI-powered shopping experiences such as virtual assistants, personalized recommendations, and intelligent customer interactions.

Working closely with Product, UX, Backend, Data, and AI teams, you'll help deliver scalable, reliable, and engaging digital commerce experiences.
