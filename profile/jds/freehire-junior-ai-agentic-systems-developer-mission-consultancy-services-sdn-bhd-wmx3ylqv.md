## JOB SUMMARY

Our client, a fast-growing SaaS company building AI-powered lending software, is looking for a hands-on, curious Junior AI / Agentic Systems Developer to build and test AI agent workflows and support customer onboarding and migration.

Working directly with the CTO, you will design autonomous and human-in-the-loop agents that automate core lending operations, including loan applications, KYC verification, credit checking, collections, and loan disbursement. You will rapidly build pilots, measure their accuracy and safety, and help move successful workflows into production.

## JOB DESCRIPTION

AI Agent Development & Integration

- Design, prototype, and iterate on multi-step AI agent workflows for loan applications, document verification, credit risk checks, collections, and disbursement triggers.
- Connect AI agents securely to Python (FastAPI) backend systems, PostgreSQL databases, and third-party APIs using tool calling and Model Context Protocol (MCP).
- Contribute features to backend systems and React/TypeScript web applications, including automated testing.
- Package agent services using Docker and deploy them on Google Cloud Platform (GCP), implementing logging, tracing, and guardrails.
- Build deterministic checks and human-in-the-loop approval steps to prevent inaccurate financial decisions and unauthorized disbursements.

Customer Onboarding & Migration

- Migrate customer data from legacy systems using repeatable import scripts, ensuring record and balance accuracy.
- Configure customer users, settings, and workflows, and support go-live activities.
- Train customer staff remotely or on-site, prepare user guides, and provide initial support.

## JOB REQUIREMENTS

Core Backend & Cloud (Must-Have)

- Solid proficiency in Python and experience building REST APIs with FastAPI (or Flask/Django).
- Strong SQL and PostgreSQL skills; database migration experience is a strong plus.
- Hands-on familiarity with Docker, Linux, and GCP services such as Cloud Run, Cloud SQL, Secret Manager, and IAM.
- Practical experience building with Anthropic Claude using the Anthropic Python SDK, Claude Agent SDK, or Claude on Google Cloud Vertex AI, including structured outputs and tool/function use.

Agentic & Workflow Engineering (Strong Plus / Willingness to Learn Fast)

- Experience with LangGraph, Google Agent Development Kit (ADK), or custom Python state machines and job queues.
- Familiarity with Model Context Protocol (MCP), prompt engineering, and evaluation techniques.
- Working knowledge of React and TypeScript.
- Familiarity with Git, Docker Compose, and automated testing (pytest).

Mindset & Background

- 2+ years of software engineering experience. Fresh graduates with strong personal or hackathon AI agent projects are encouraged to apply.
- Strong sense of ownership, security, data privacy, and financial accuracy.
- Ability to explain technical concepts clearly to non-technical users.
- Based in Jakarta, Indonesia.
- Strong Bahasa Indonesia communication skills and working proficiency in English.
- Willingness to travel occasionally for customer onboarding.
