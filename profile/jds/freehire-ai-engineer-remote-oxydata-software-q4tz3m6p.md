# **AI Engineer (GenAI/RAG Platform)**

Location: Petaling Jaya, Selangor, Malaysia  
Work Mode: Remote

Employment type: Permanent

Oxydata Software Sdn Bhd established since 2012, helping regional enterprises drive digital transformation through Agentic AI Services, AI Automation & Integration, Data Engineering, AI Training, and IT Managed Services. We are a lean, high-impact team where engineers work directly on cutting-edge AI products serving enterprise clients across Malaysia and the region.

We are seeking an experienced AI Engineer (GenAI/RAG Platform) to build and deploy our AI-powered recruitment platform, OPAL.

### **Responsibilities**

- Design, develop, and maintain React.js dashboards for recruiters and hiring managers.
- Implement backend services using FastAPI, including REST API endpoints, report generation, data management, and cron job scheduling.
- Build and optimize Python-based AI processing pipelines for CV ingestion, AI scoring, and candidate report generation.
- Develop and maintain RAG pipelines, including chunking, embeddings, vector search, reranking, and retrieval grounding.
- Integrate and deploy agentic AI workflows using tools such as LangGraph, CrewAI, or N8N for autonomous recruitment processes.
- Leverage Supabase, PostgreSQL, and pgvector for hybrid keyword and semantic search functionalities.
- Integrate external APIs, including ATS platforms, AI APIs (Claude, OpenAI), and email delivery systems.
- Apply DevOps best practices for version control, API design, testing, deployment, and error handling.
