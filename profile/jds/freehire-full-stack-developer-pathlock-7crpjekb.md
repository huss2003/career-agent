**ABOUT THE ROLE**

Pathlock’s Professional Services organization builds and maintains internal enterprise web applications that support our Professional Services teams and customers. These are data-driven, form-heavy web applications built with React + TypeScript (Vite), a Node.js (TypeScript) REST API, and a Microsoft SQL Server database using row-level security.

We are looking for a mid-senior Full-Stack Developer who will own features end to end – from database to UI and contribute to design decisions alongside the solution architect. You will help shape and deliver the product roadmap as these applications continue to grow in scope and capability. The team embraces AI-assisted development to deliver faster and work smarter.

**KEY RESPONSIBILITIES**

- **Front end:** Build and extend the UI, including dynamic schema-driven forms, conditional fields, repeatable tables, validation, progress tracking, export and print/PDF output.
- **APIs:** Build secure Node.js REST APIs (Express, Fastify or NestJS) using parameterized queries and transactional header/detail upserts.
- **Database:** Design and evolve the SQL Server schema, stored procedures, views, row-level security policies and migration scripts.
- **Security:** Implement authentication and authorization: OTP login, session management, role-based personas, staff vs. customer access and least-privilege database permissions.
- **Deployment:** Deploy and manage the application on IIS (IIS as a reverse proxy with URL Rewrite + ARR, Node.js running as a Windows service, web.config, bindings/SSL) and help plan the move toward Azure.
- **Roadmap delivery:** Own and ship new roadmap features end to end, from requirements and data model through API, UI and release.
- **Quality:** Write unit, integration and end-to-end tests; participate in code reviews; contribute to CI/CD pipelines and technical documentation.
- **Mentoring:** Guide and mentor junior developers through pairing, reviews and knowledge sharing.
- **AI-assisted development:** Use AI coding assistants and agents (e.g. GitHub Copilot, Cursor, ChatGPT/Claude) to accelerate design, coding, refactoring, testing and documentation, while reviewing all AI-generated code for correctness, security and maintainability.
- **AI for efficiency:** Identify opportunities to apply AI/LLM capabilities within our applications and workflows (e.g. drafting content, summarizing inputs, smart validation) to improve efficiency for Professional Services teams and customers.

**REQUIRED QUALIFICATIONS**

- **Experience:** 4-8 years of professional full-stack development experience.
- **Front end:** React 18+ with hooks or Vue 3 (Composition API), strict TypeScript, Vite, modern CSS and complex form handling.
- **SQL Server:** Understanding of T-SQL, relational schema, stored procedures, views, functions, etc
- **Security:** OWASP Top 10, SQL injection prevention, authentication patterns, secrets management and least-privilege design.
- **Infrastructure & tools:** IIS on Windows Server, PowerShell and Git.
- **AI tools:** Hands-on experience using AI coding assistants in day-to-day development, with strong judgment on prompting, verifying output and safeguarding code and data (no secrets or customer data in prompts).

- **Front end:** Vite, modern CSS and complex form handling.
- **Back end:** Node.js 20+ LTS with TypeScript; REST API frameworks such as Express, Fastify or NestJS; SQL Server access via mssql/tedious or an ORM/query builder such as Prisma, TypeORM or Knex; async programming, modular architecture; npm/pnpm.
- **SQL Server:** Strong T-SQL, schema design, indexing, SQL Server RLS / SESSION\_CONTEXT; logins, users and permissions (including orphaned users); backup and restore.

- **AI/LLM integration:** Building features with LLM APIs (OpenAI, Azure OpenAI or similar), prompt engineering, retrieval-augmented generation (RAG), and evaluating AI output quality.
