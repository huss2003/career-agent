**2. How do you use AI coding tools across the development lifecycle?** _(likely question)_

I use Claude Code daily. I plan the work first, scaffold with the agent, have it draft tests, then review every diff by hand before it goes in. I hold Anthropic's Claude Code in Action and Claude Code 101 certifications. I have not used Cursor or GitHub Copilot as my main tools, but the habits carry over: give the tool clear context, check its output, and keep ownership of the design.

**3. How do you verify AI-generated output and avoid over-trusting it?** _(likely question)_

In PageForge, my account-based marketing page generator, the AI drafts only from approved facts. A deterministic validator then flags unsupported numbers, and a reviewer signs off claim by claim before anything is published. In multi-agent-research-crew, a verifier agent does claim-level citation checking. I apply the same rule to code: fluent output is still a draft, and review is the bottleneck, not generation.

**4. Describe a project you own end to end, including testing.** _(likely question)_

Orbital Surplus (orbital-surplus.vercel.app) is a full-stack store, a fictional demo brand running Stripe in test mode. Stock holds are race-safe: one transaction with a conditional UPDATE, so only one shopper wins the last unit. Payment confirmation is idempotent, whether it arrives through the return page or a signed Stripe webhook. It has 9 end-to-end API tests. Node 20 and Postgres (Neon) on the back end. My portfolio site (hussain-singapuri.vercel.app) has a booking backend with 10 end-to-end API tests.
