**About Betterworks**

Betterworks is HR software to align, develop, and activate your workforce for business growth. **What You’ll Be Doing**

We are hiring a **Software Engineer I – Full Stack (AI-Native)** to build and enhance a complex enterprise performance management SaaS platform that supports decision-making at scale across large enterprises.

This role is for a product engineer who can build across the stack and use modern AI-assisted development tools effectively throughout the SDLC. You will own features and fixes from design through production readiness, using AI to accelerate execution while maintaining strong standards for correctness, testing, maintainability, and collaboration.

This is **not an AI research or ML engineering role**. It is a **full-stack software engineering role** for engineers who know how to use AI tools well.

- Design, build, and enhance product features across frontend and backend systems
- Write clean, efficient, and maintainable code using sound software engineering practices
- Collaborate with product, design, QA, and other engineers to convert requirements into implementation plans
- Own small-to-medium features or well-scoped technical improvements end-to-end
- Write and maintain unit, integration, and E2E tests
- Investigate incidents, troubleshoot issues, and improve reliability
- Participate in code reviews and uphold engineering standards
- Use AI tools to accelerate coding, debugging, refactoring, testing, documentation, and delivery workflows
- Apply judgment in verifying AI outputs, identifying hallucinations, and protecting code quality
- Work effectively in a remote, async environment across multiple time zones
- Proficient in using AI coding tools to complete engineering tasks
- Strong prompting techniques for implementation, debugging, refactoring, and testing
- Ability to manage context effectively across files, requirements, logs, errors, and partial outputs
- Ability to verify, correct, and safely integrate AI-generated code
- Familiarity with tools such as GitHub Copilot, Claude Code, Cursor, or similar
- Ability to use AI for parts of the SDLC: code generation, debugging, test generation, PR preparation, documentation, and change analysis
- Ability to reason about when AI should be used, when it should not, and where human review is critical
- Can translate vague requirements into structured prompts and execution plans
- Can create bounded workflows for repeatable tasks such as bug triage, test generation, and small feature scaffolding
- Can inspect, verify, and improve AI outputs rather than over-trusting them
- Can use AI to accelerate work while maintaining ownership of architecture, correctness, and quality
