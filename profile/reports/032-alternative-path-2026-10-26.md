**About Alternative Path**

Alternative Path is a strategic operations consulting firm, founded in 2020, that helps growth-stage and enterprise organizations build high-performing, India-based teams across Technology Ops, Data Ops, Business Intelligence, and Finance. Every engagement is senior-led, and the firm has delivered 50+ engagements for clients across the US, Europe, and Australia.

**About the Role**

**​** We're looking for a Full Stack Developer who will design, build, and manage applications for our clients end to end. You'll work across the stack — from database schema to API design to frontend UX — and you'll be expected to use modern development tooling, including LLM-assisted development, to work faster and smarter without compromising code quality.

### Requirements

**Responsibilities**  
• Design, develop, test, and maintain full-stack web applications for client engagements  
• Build and maintain RESTful/GraphQL APIs and backend services using Node.js and Python  
• Develop responsive, performant frontends using ReactJS  
• Design and manage relational databases using MySQL and PostgreSQL, including schema design, query optimization, and migrations  
• Deploy, monitor, and manage applications on AWS  
• Use LLM-powered tools (e.g., Claude Code, GitHub Copilot, Cursor, or similar) as part of your regular development workflow — for scaffolding, code review, debugging, test generation, and documentation

• Write clean, maintainable, well-tested code and participate in code reviews

• Collaborate directly with client stakeholders to understand requirements and translate them into technical solutions

• Own applications post-launch — bug fixes, feature enhancements, performance tuning, and ongoing support

• Contribute to architecture and technical decisions across projects  
• Maintain documentation for systems you build and manage

**Required Skills & Experience**  
• 2–3 years of professional experience in full-stack web development

• Strong hands-on experience with Node.js and ReactJS

• Proficiency in Python for backend/scripting work

• Experience with AWS (EC2, S3, Lambda, RDS, or similar core services)

• Strong SQL skills with MySQL and PostgreSQL — schema design, indexing, query optimization

• Comfort working across the full stack, from database to deployment

• Practical experience using modern AI/LLM developer tools in daily coding workflows

• Solid understanding of REST API design and integration • Familiarity with Git-based version control and CI/CD workflows

• Ability to work directly with clients and manage multiple engagements

• Strong debugging and problem-solving skills

**Nice to Have**

• Experience with containerization (Docker) and infrastructure-as-code (Terraform/CDK)

• Exposure to TypeScript

• Experience in a client-services / consulting environment

• Familiarity with QA/testing practices and tools (given our QA services background)

• Experience building or integrating AI-powered features into applications
