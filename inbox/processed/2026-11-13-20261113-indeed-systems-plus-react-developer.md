Position Summary

The React Developer is responsible for designing, developing, and maintaining custom web applications used to support contact center operations. This position focuses on building applications that make it easier for employees to perform their jobs, access information, and complete customer interactions efficiently.

The developer will work closely with the Contact Center Technology team, Product Management, and business stakeholders to develop user-friendly applications that connect with contact center platforms, CRM systems, and other enterprise applications.

The role requires strong React development skills, an understanding of API integrations, and the ability to build reliable applications that are easy to use and maintain.

Key Responsibilities

Application Development
- Design, develop, and maintain web applications using React, JavaScript, and TypeScript.
- Build user interfaces that support contact center agents, administrators, and operational teams.
- Develop reusable components and maintain consistent application design and behavior.
- Translate business and technical requirements into working application features.
- Improve existing applications based on user feedback, performance, and changing business needs.
- Troubleshoot application issues and implement fixes.

API Integration and Application Connectivity
- Integrate React applications with REST APIs and other web services.
- Work with backend developers and integration teams to connect applications with enterprise systems.
- Support integrations involving contact center platforms, CRM systems, and internal applications.
- Handle application data, authentication, error handling, and system responses appropriately.
- Work with technical leadership to identify integration requirements and dependencies.
- Troubleshoot issues involving application connectivity and data exchange.

User Experience and Operational Efficiency
- Build applications that are simple, intuitive, and efficient for employees to use.
- Work with business and operational teams to understand how applications are used in daily workflows.
- Help reduce unnecessary steps, duplicate data entry, and manual processes.
- Develop responsive interfaces that support different screen sizes and working environments.
- Consider application performance, accessibility, and usability when designing features.
- Recommend improvements that simplify workflows and improve the user experience.

Application Quality and Support
- Write clean, maintainable, and well-documented code.
- Participate in code reviews, testing, and technical design discussions.
- Develop unit and component tests and support integration testing.
- Troubleshoot production issues and support application releases.
- Follow established development, security, and change management practices.
- Use Git and established development workflows to manage application changes.
- Support application monitoring, error handling, and performance improvements.

Team Collaboration
- Work closely with the Director and other developers on application architecture and technical design.
- Collaborate with IVR/IVA developers, platform administrators, and integration teams.
- Participate in planning discussions and provide development estimates.
- Communicate technical challenges, dependencies, and progress.
- Share technical knowledge and contribute to development standards and reusable components.
