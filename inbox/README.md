# Inbox

Drop a job here to have the agent evaluate it and tailor your CV. Adding a file starts the **Job agent** workflow.

One file per job (or several URLs in one file):

```
note: found on Indeed, referral from Ravi
https://jobs.ashbyhq.com/acme/1234
```

Or paste the whole job description into the file when the posting needs a login (LinkedIn, Naukri).

After the run, the file moves to `inbox/processed/` and the results appear in `profile/data/last-run.md`.
